# 0630thesis 仿真与实物实验内容方案（深化版）

> 目标：围绕新的第三、四、五章设计精简、可落地、便于测量和便于展示的实验体系。实验方案尽量复用现有 Franka/主端/力传感器/长工具/柔性材料平台，不额外搭建复杂系统。本文档同时给出可对比的近期方法选择依据、仿真实验设计、实物实验设计和论文结果组织方式。

## 0. 实验总原则

本论文实验不应追求平台复杂度，而应追求论证闭环清楚。导师意见中最关键的要求是：第三章要证明合作博弈力-位控制器相较阻抗控制、MPC/QP 等基线方法有自身价值；第四章要证明人机动态仲裁在柔性接触人机输入场景中有必要；第五章要把前两章组合起来做完整实物验证，而不是再提出一个“缝合式新方法”。

所有实验都应围绕同一类任务：人机协同柔性接触操作。具体工况可以分成无 RCM 和有 RCM 两类。无 RCM 工况用于证明方法不局限于手术或长工具；有 RCM 工况用于覆盖导师关心的长工具、固定点-轴线或手术训练边界。RCM 是实验边界条件，不是全文题名中的研究对象。

实验应尽量满足五个条件：改动小、可预测、可测量、可对比、可展示。改动小指复用现有 Franka、主端设备、长工具、力传感器和柔性材料；可预测指各对比方法的优势和不足在力-位指标上有明确预期；可测量指指标能直接由机器人状态、力传感器和日志计算；可对比指每组实验只改变一个关键因素；可展示指最终图表能清楚支持章节结论。

## 1. 可对比方法检索与取舍

### 1.1 经典且必须保留的基线

**笛卡尔阻抗控制。** 阻抗控制是接触任务中最基础的基线，因为它直接描述力与位置、速度、加速度之间的动态关系。其优点是实现简单、实时性好、容易在 Franka 上部署；缺点是位置精度和接触力安全主要依赖固定刚度、阻尼等参数整定，遇到变刚度环境时容易出现“强刚度导致力峰值、弱刚度导致轨迹漂移”的折中问题。该方法应作为第三章控制器对比的第一基线。文献与实现方面，可参考通用笛卡尔阻抗控制和 ROS/Franka 可复用实现；已有 C++ 笛卡尔阻抗控制实现包含 ROS 集成、滤波、限幅和安全特性，并在 Franka Emika Panda 等机器人上测试，适合作为工程参考。citeturn531358academia0

**混合力/位置控制。** 混合力/位置控制通过方向选择矩阵在切向做位置控制、法向做力控制，是力控任务中的经典基线。它的优势是物理含义清楚，特别适合表面扫描：切向跟踪路径，法向维持接触力。缺点是方向分解和环境法向需要较准确，且切换或固定选择矩阵难以处理柔性环境刚度突变。作为第三章基线，它能直接回答“为什么不能只用经典力/位分解”。力控制领域通常将力控制与位置控制结合使用，并指出机械加工、打磨、抛光、去毛刺和表面扫描是典型应用。citeturn765848search1

**固定优先级合作博弈。** 这是本文方法的内部消融基线。它保留合作博弈反馈结构，但将 `α_FP` 固定为 0.2、0.5、0.8 三档。该基线能说明“合作博弈反馈律”和“动态力安全裕度调度”分别贡献了什么。固定 `α_FP` 在某一工况可能单项指标较好，但跨软硬区域时会暴露失配问题。

### 1.2 建议作为增强基线的方法

**MPC/QP 力-位协调。** MPC/QP 能把位置误差、力误差和约束写入优化问题，理论表达强，适合作为合作博弈方法的对比对象。为了降低实现成本，实物实验不建议做完整非线性 MPC，而建议采用线性化法向模型加 OSQP/QP：以 `e_p,e_v,e_f,σ_f` 为状态，在短预测时域内最小化二次代价并限制控制输入和力边界。仿真中可完整实现，实物中可只作为 50-100 Hz 的简化 QP 基线。

**CBF-QP/Force-Constrained CBF。** 近年安全关键控制中已有将接触力约束解释为 force-constrained CBF 的工作，思路是在名义柔顺控制器外层用二次规划修正关节速度或任务速度，以严格满足交互力约束。该类方法适合作为“力安全边界保护”基线，尤其用于展示本文方法与安全约束方法的关系：CBF-QP 对力越界最强，但可能更保守、轨迹覆盖下降；本文方法追求的是力安全、位置精度和人机修正的综合折中。Guarding Force 在未知环境下将力约束写成控制屏障函数，并用 QP 修正名义柔顺控制器，在 UR3e 上进行了实验验证。citeturn285122academia0

**自适应/变阻抗控制。** 变阻抗控制与本文动态 `α_FP` 的物理动机接近，适合作为第三章补充基线。实现时不需要学习模型，可设置基于接触力误差和刚度估计的 `K_z(t),D_z(t)` 调度规则。预期表现是：比固定阻抗更好，但由于不是从位置目标和力目标的统一代价中求解，解释力和综合折中不如合作博弈清楚。文献中也有结合 MPC 与变阻抗的工作，并在 Franka Panda 上做过仿真和实物实验，但完整深度模型预测变阻抗控制实现成本较高，不建议作为主实物基线。citeturn531358academia3

### 1.3 只用于文献综述、不建议作为主实验基线的方法

**ForceMimic、FORGE、FoAR、Force Policy、ForceVLA2 等学习式力控或力感知策略。** 这类方法代表当前 contact-rich manipulation 的前沿趋势，通常结合视觉、力觉、模仿学习、强化学习或大模型策略。它们的优势是能处理复杂任务和非结构化场景；但本论文当前目标是控制科学硕士论文的可解释、可实现、可对比实验，且现有平台不一定具备训练数据、视觉系统和长时间采集条件。因此建议在第一章研究现状中提及，但不作为主实验基线。ForceMimic 使用 force-motion capture 和 hybrid force-motion imitation learning 处理接触丰富任务；FORGE 使用 force threshold 和 dynamics randomization 进行 sim-to-real 力引导探索；这些工作能说明显式力信息的重要性，但实验成本明显高于本文需要。citeturn686808academia2 citeturn686808academia0

**共享自主增量学习或通信对齐方法。** 这些方法可作为第四章人机协同研究现状背景，但不建议进入实物对比。近期共享自主工作强调从反复交互中学习辅助策略，或通过通信改变人类干预方式；这些方向与本文人机仲裁相关，但需要被试实验、任务库和长期交互数据，不适合在当前论文修改阶段作为主实验。citeturn636659academia1 citeturn636659academia2

**RCM 专项控制方法。** RCM 相关新工作可作为第五章有 RCM 工况的背景，不应作为第三章核心基线。近期有基于 admittance control 的 adaptive RCM 以及 differential kinematics RCM tracking 方法，说明 RCM 可通过导纳或运动学约束实现，但本文的主要问题不是提出新的 RCM 控制器，而是在有/无 RCM 两类边界下验证力-位协同和人机仲裁。citeturn192209academia0 citeturn192209academia1

## 2. 实验总框架

建议将实验分为三层，对应第三、四、五章。

| 层级 | 对应章节 | 实验目的 | 主要改变因素 | 固定因素 |
|---|---|---|---|---|
| 控制器层 | 第三章 | 验证合作博弈力-位控制器相较经典控制器的综合折中能力 | 控制器类型 | 参考轨迹、人类输入、柔性环境、力阈值 |
| 仲裁层 | 第四章 | 验证动态人机仲裁能接受安全切向修正、抑制危险法向输入 | 仲裁策略 | 第三章控制器、柔性环境、输入序列 |
| 系统层 | 第五章 | 验证控制器和仲裁器组合后的整体效果与消融结果 | 是否启用控制器/仲裁/安全投影 | 平台、任务、材料、指标 |

实验数量不宜过多。建议每类实物实验 5-8 次重复，优先保证数据质量和可解释性。若时间紧张，第三章做控制器对比实物，第四章做仲裁对比实物，第五章做完整方法和两个消融实物即可。仿真中可以做更丰富的参数敏感性，用于支撑实物现象。

## 3. 仿真实验方案

### 3.1 仿真实验 A：第三章力-位协同控制器对比

**目的。** 验证合作博弈控制器在柔性接触任务中相对固定阻抗、混合力/位、MPC/QP 和固定 `α_FP` 的综合表现。

**任务设置。** 使用二维或三维简化接触模型。接触点沿 `x` 方向扫描，`z` 方向为法向压入。环境采用分段 Kelvin-Voigt 模型：低刚度区、中等刚度区、高刚度区。扫描路径可为直线或轻微曲线，期望法向力 `F_d=0.6~1.0 N`，安全边界 `[F_min,F_max]` 依据实物材料设置，如 `[0.35,1.2] N`。

**对比方法。**

1. 固定笛卡尔阻抗：`K_z,D_z` 固定。
2. 混合力/位置控制：切向位置 PD，法向力 PI/PID。
3. 固定 `α_FP=0.2,0.5,0.8` 的合作博弈。
4. 简化 MPC/QP：线性增广模型，短时域二次规划。
5. 本文动态 `α_FP` 合作博弈。

**指标。**

```text
E_F^RMS = sqrt(mean((y_f - F_d)^2))
|e_F|max = max(|y_f - F_d|)
T_vio = Ts * sum(1[y_f < F_min or y_f > F_max])
E_T^RMS = sqrt(mean(||P_T(x-x_d)||^2))
E_N^RMS = sqrt(mean(||P_N(x-x_d)||^2))
J_F = std(y_f[k] - y_f[k-1])
J_x = RMS jerk or std(diff acceleration)
T_comp = mean and max computation time
```

**预期现象。** 固定高刚度阻抗的位置误差较小，但高刚度区力峰值较大；混合力/位控制力误差较低，但刚度突变时容易出现法向振荡或切向滞后；MPC/QP 指标较稳，但计算时间较大，实物频率可能受限；固定 `α_FP` 在某一刚度段表现较好，但跨刚度段失配；本文方法不一定在所有单项指标上最优，但应在 `T_vio`、`E_T^RMS`、`J_F` 和 `T_comp` 的综合评分上表现较好。

**推荐图表。**

- 接触力-时间曲线，标注 `F_min,F_d,F_max`；
- `α_FP` 与估计刚度/力安全裕度时序；
- 不同方法的力 RMS、越界时间、位置 RMS 柱状图；
- 计算时间箱线图或表格；
- 软/中/硬区分段统计表。

### 3.2 仿真实验 B：第四章动态仲裁策略对比

**目的。** 在相同第三章控制器下验证不同人机仲裁策略对人类输入的处理差异。

**任务设置。** 使用同一柔性表面扫描模型。设计四类人类输入序列：安全切向修正、危险法向压入、短时扰动、持续目标重定向。输入可以预设为时间函数，不需要真实人参与，从而保证重复性。

**对比方法。**

1. 直接叠加人类输入；
2. 固定比例共享控制；
3. 单因素 S 型仲裁；
4. 多因素仲裁但无安全投影；
5. 本文含切向/法向分解和安全投影的动态仲裁。

**指标。**

```text
R_acc = accepted tangential correction / requested tangential correction
R_sup = suppressed unsafe normal input / requested unsafe normal input
T_vio = force violation time
E_path = distance between executed path and desired corrected path in safe tangent segment
α_HR smoothness = RMS(dot α_HR) or std(diff α_HR)
F_peak = max y_f in unsafe push segment
```

**预期现象。** 直接叠加方法能接受人类切向修正，但危险法向压入导致力峰值或越界；固定比例方法无法根据风险区分输入；S 型仲裁对持续输入有响应，但对切向/法向差异不足；无安全投影的多因素仲裁比固定比例好，但在高刚度区仍可能放大法向输入；本文方法应保持较高 `R_acc` 和较高 `R_sup`，并降低危险输入阶段的 `F_peak` 和 `T_vio`。

### 3.3 仿真实验 C：第五章综合闭环和参数敏感性

**目的。** 验证第三章控制器与第四章仲裁器组合后的系统表现，并用仿真完成参数敏感性分析，为实物实验选择参数提供依据。

**工况。**

1. 无 RCM 柔性表面扫描：软区、硬区、缺陷绕行、危险法向输入。
2. 有 RCM 长工具接触扫描：固定点-轴线约束、柔性表面接触、短路径扫描。

**消融方法。**

1. 完整方法：动态 `α_FP` + 动态 `α_HR` + 安全投影；
2. 固定 `α_FP`：只启用人机仲裁；
3. 固定 `α_HR`：只启用力-位控制；
4. 无安全投影：动态仲裁但不投影人侧参考；
5. 无动态仲裁：固定比例融合和固定优先级。

**参数敏感性。** 只选 4 类参数：`α_FP` 下限、`λ_FP`、`λ_HR`、安全余量 `Δ_F`。每类取三档，使用仿真完成统计，不建议在实物上做大网格。

**预期图表。**

- 综合评分表；
- 力安全、轨迹覆盖、人类修正、RCM 误差四组柱状图；
- 参数敏感性热图；
- 完整方法与消融方法的典型时序图。

## 4. 实物实验准备

### 4.1 统一平台与硬件

优先复用现有设备，不搭建复杂新平台。

| 模块 | 推荐使用 | 备注 |
|---|---|---|
| 机械臂 | Franka Panda/FR3 | 使用已有 ROS/Franka 控制接口；优先任务空间速度或力矩接口。 |
| 主端 | Novint Falcon 或已有手柄 | 采集人类位移/速度/交互强度；第四、五章使用。 |
| 力测量 | 末端 6D 力传感器或 Franka 外力估计 | 若两者都有，以 6D 传感器为主，Franka 外力估计用于对照。 |
| 接触工具 | 圆头探针、短杆、长工具/腹腔镜抓钳 | 工具端尽量圆滑，避免破坏柔性材料。 |
| 柔性材料 | 海绵、硅胶块、泡棉、橡胶条 | 用 2-3 块不同硬度材料形成变刚度区域。 |
| RCM 结构 | 简化套管、固定孔或虚拟 RCM 点 | 可沿用现有长工具实验平台；RCM 误差通过几何计算获得。 |

### 4.2 标定与数据记录

实物实验前应完成：

1. 力传感器零偏标定：每次实验开始前静止 3-5 秒取平均零偏。
2. 工具坐标标定：记录法兰到接触点的位移，统一坐标变换。
3. 接触法向确定：平面材料可固定为世界 `z` 方向，曲面或倾斜面可由初始接触姿态估计。
4. RCM 点标定：记录固定孔/套管中心，计算点到工具轴线距离。
5. 采样频率：建议控制 100 Hz，日志 100 Hz 或更高；若 Franka 内环更高，保存下采样数据即可。
6. 硬安全：设置 `F_hard`、速度上限、关节力矩上限和急停策略。硬安全事件应记录，但不纳入正常性能改善结论。

推荐日志字段：

```text
时间戳 t
关节 q, dq, τ
末端/法兰位姿 x_F, R_F
工具接触点位置 x_T
期望轨迹 x_d, x_r, x_h, x_h_safe
接触力 f_e, 受控法向力 y_f
α_FP, α_HR, β, ρ_F, K_hat
RCM 误差 e_gc
主端输入 Δx_m, v_m, f_h 或等效输入强度
控制输入 u, 计算时间 T_comp
```

## 5. 第三章实物实验：力-位协同控制器

### 5.1 实验 3-P1：无 RCM 柔性表面恒力扫描

**目的。** 补足导师要求的无 RCM 实物实验，证明第三章控制器不是依赖 RCM 场景成立。

**装置。** Franka 末端安装圆头探针或短接触杆，下方固定海绵/硅胶材料。若有两种刚度材料，可沿扫描路径拼接软区和硬区；若只有一种材料，可通过在部分区域下方加硬支撑形成等效刚度变化。

**任务。** 机器人沿 `x` 方向扫描 8-12 cm，同时维持 `F_d=0.5~0.8 N` 的法向接触力。每次实验 20-40 秒，每个方法重复 5 次。

**对比方法。** 固定阻抗、混合力/位、固定 `α_FP=0.5`、本文动态 `α_FP` 合作博弈。若时间允许，加入简化 QP 或 CBF-QP。

**预期结果。** 本文方法在力越界时间、力抖动和轨迹误差之间取得更稳定折中。固定阻抗在硬区出现力峰值；混合力/位力误差可能较好，但切向路径跟踪或法向抖动较明显；固定 `α_FP` 对不同刚度段适应性较差。

### 5.2 实验 3-P2：有 RCM 长工具柔性接触扫描

**目的。** 作为第三章附加工况或第五章预备数据，验证控制器在长工具几何边界下仍可执行。

**装置。** Franka 末端安装长工具，通过简化套管或虚拟 RCM 点接触柔性材料。工具尖端沿短路径扫描，控制器在法兰或接触点等效空间中执行。

**任务。** 选择 3-5 cm 的短扫描路径，期望力设为 0.3-0.6 N，重复 5 次。该实验重点不追求复杂任务，而是要同时记录接触力和 RCM 误差。

**对比方法。** 固定阻抗、固定 `α_FP`、本文动态 `α_FP`。MPC/QP 可只在仿真中对比，不强制进入 RCM 实物实验。

**预期结果。** 过低位置优先级会放大 RCM 或法兰姿态扰动，过高位置优先级会提高接触力峰值；动态方法应在 RCM 误差不过度增加的情况下改善力安全。

## 6. 第四章实物实验：人机动态仲裁

### 6.1 实验 4-P1：安全切向修正

**目的。** 验证操作者的有效切向修正能进入参考轨迹。

**装置。** 使用无 RCM 柔性表面扫描平台即可。操作者通过 Falcon 在扫描中给出横向偏移，模拟绕开局部缺陷或扩大覆盖区域。

**对比方法。** 直接接受、固定比例、S 型仲裁、无安全投影仲裁、本文动态仲裁。控制器固定为第三章本文控制器。

**指标。** `R_acc`、切向轨迹偏移误差、力峰值、力越界时间、`α_HR` 平滑性。

**预期结果。** 本文方法应接近直接接受方法的切向修正能力，但比直接接受方法具有更小的法向力扰动。

### 6.2 实验 4-P2：不安全法向压入

**目的。** 验证安全投影和动态仲裁能削弱可能导致过压的人类输入。

**任务。** 机器人扫描过程中，操作者在 5-8 秒窗口内给出向下压入输入。安全投影应削弱法向分量，而尽量不影响切向推进。

**指标。** `R_sup`、`F_peak`、`T_vio`、法向参考削弱量、切向路径误差。

**预期结果。** 直接接受和固定比例方法力峰值更高；S 型仲裁有所改善；本文方法应最大限度降低 `F_peak` 和 `T_vio`，同时保留必要切向运动。

### 6.3 实验 4-P3：短时扰动与持续干预

**目的。** 区分短时误触和持续明确意图。

**任务。** 设计两类输入：0.3-0.5 秒短时脉冲；3-5 秒持续修正。观察 `α_HR` 是否对短时输入缓慢响应，对持续输入平滑上升。

**指标。** `α_HR` 峰值、上升时间、恢复时间、参考轨迹突变量、力峰值。

**预期结果。** 本文方法应抑制短时脉冲造成的权重突跳，并接受持续修正。

## 7. 第五章综合实物实验

第五章不需要比第三、四章做更多算法，但需要把实验组织得完整、统一、可解释。

### 7.1 实验 5-P1：无 RCM 综合柔性表面操作

**目的。** 展示完整方法在普通工业柔性接触任务中的闭环效果。

**任务。** 机器人沿柔性材料表面扫描，路径中设置一个“缺陷区域”或“重点区域”。操作者通过主端给出切向绕行/覆盖修正，同时在某一段给出危险法向压入。材料中包含软硬变化。

**对比组。**

1. 固定阻抗 + 固定比例接受人类输入；
2. 第三章控制器 + 无人机仲裁；
3. 固定控制器 + 第四章仲裁；
4. 第三章控制器 + 第四章仲裁完整方法。

**预期现象。** 完整方法能够绕开或覆盖目标区域，同时减少危险法向输入导致的力越界。仅力-位控制没有人类修正能力；仅人机仲裁缺少动态力-位执行调度，在高刚度区表现较差。

### 7.2 实验 5-P2：有 RCM 长工具柔性操作

**目的。** 展示完整方法在长工具/手术训练式边界中的可执行性。

**任务。** 长工具通过固定点接触柔性材料，执行短距离扫描或轻触压入。操作者给出切向修正和法向误推。实验不追求复杂缝合动作，以保证可重复性和安全性。

**对比组。** 固定阻抗、仅第三章控制器、完整方法。若时间不足，可以不做所有仲裁基线，但必须展示完整方法和至少一个固定基线。

**指标。** `E_F^RMS`、`|e_F|max`、`T_vio`、`E_gc^RMS`、`E_gc^max`、`R_acc`、`R_sup`、计算时间。

**预期现象。** 完整方法应在不明显增大 RCM 误差的情况下减少危险法向压入造成的力峰值，并保持切向修正能力。

### 7.3 实验 5-P3：参数敏感性小规模实物验证

仿真中做全参数敏感性，实物只选两个参数：`λ_FP` 和安全余量 `Δ_F`。每个参数三档，每档 3 次即可。目的不是找全局最优参数，而是证明参数变化符合理论直觉。

预期：`λ_FP` 过大时力抖动增加，过小时力越界响应滞后；`Δ_F` 过大时保守、轨迹覆盖下降，过小时危险输入抑制不足。

## 9. 推荐综合评分方式

若需要一个综合评分用于第五章展示，可以采用归一化加权形式，但必须说明该评分只是展示工具，不是理论目标。

```text
S = w_F * norm(E_F^RMS)
  + w_vio * norm(T_vio)
  + w_p * norm(E_T^RMS)
  + w_gc * norm(E_gc^RMS)
  + w_h * (1 - R_acc)
  + w_s * (1 - R_sup)
  + w_t * norm(T_comp)
```

权重建议不要调得太复杂。可以取 `w_F,w_vio,w_p,w_gc,w_h,w_s,w_t` 为固定值，并说明权重只用于综合排序，单项指标仍单独报告。若某个工况无 RCM，则 `w_gc=0`。

## 10. 预计结论边界

预计最容易得到的可靠结论包括：

1. 相比固定阻抗，合作博弈力-位控制在变刚度柔性接触中能降低力峰值或越界时间，同时保持可接受轨迹误差。
2. 相比固定 `α_FP`，动态 `α_FP` 能随力安全裕度或刚度变化移动折中点，减少固定参数失配。
3. 相比直接接受人类输入，动态人机仲裁能保留切向修正并抑制危险法向输入。
4. 完整方法不一定在单项力 RMS 上总是最优，但在力安全、轨迹覆盖、人类修正和 RCM 合规的综合指标上更稳定。
5. 第五章的价值是综合验证，不是提出第三个理论方法。

不建议写的结论包括：

- “本文方法显著优于所有方法”；
- “全面证明了柔性接触操作安全”；
- “解决了手术和工业中的通用操作问题”；
- “模糊仲裁方法具有强理论创新”。

更稳妥的写法是：“在本文所设柔性材料、接触力范围和控制频率条件下，实验结果表明所提方法能够在力安全、轨迹误差和人类修正之间取得较好的综合表现。”

## 11. 实施优先级

若时间紧张，按以下顺序做：

1. 第三章无 RCM 实物控制器对比：固定阻抗、混合力/位、本文方法。
2. 第四章不安全法向压入实物仲裁对比：直接接受、固定比例、本文方法。
3. 第五章有 RCM 完整方法实物展示：完整方法与固定基线。
4. 仿真补齐 MPC/QP、CBF-QP、参数敏感性。
5. 根据结果选择最清楚的 3-4 张图进入正文，其余放附录或不放。

该顺序优先满足导师最关心的“实物实验”和“控制器对比”，同时避免在复杂平台搭建上消耗时间。

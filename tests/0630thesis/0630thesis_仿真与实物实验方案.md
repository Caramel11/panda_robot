# 0630thesis 仿真与实物实验方案

面向“基于合作博弈的人机协同柔性接触操作力-位协调控制研究”的精简可实现实验设计

本文档给出后续补充仿真和实物实验的实施方案。实验设计遵循三个原则：不新建复杂平台，尽量复用现有
Franka 机械臂、主端设备、长工具、简化 RCM
结构和已有仿真代码；对比方法以易实现、可解释、能支撑论文论证为主，而不是追求复杂学习系统；实验现象应能由控制变量和评价指标直接解释，避免只靠主观描述证明方法有效。

实验总目标是分别验证第三章、第四章和第五章的逻辑。第三章验证合作博弈力—位控制器相对于常用力/位协调方法的综合折中；第四章验证人机动态仲裁能够接受安全切向修正并抑制危险法向输入；第五章验证两层方法组合后，在无
RCM 和有 RCM
两类柔性接触任务中仍具有可重复的力安全、轨迹精度和实时性表现。

# 1 可对比方法筛选

实验基线应分为“必须实现的主基线”和“文献讨论的先进方法”。主基线需要能够在现有代码中较快实现，并能直接测量同一组指标；先进方法可用于绪论和实验讨论，说明当前领域发展方向，但不宜作为必须复现实验对象。原因在于学习式接触操作方法通常需要额外数据采集、视觉或触觉系统、训练时间和任务专用策略，这与当前论文补实验的时间约束不匹配。

| **方法**                 | **实现方式**                                                                       | **实现便利性**                                                        | **在论文中的作用**                                               |
|--------------------------|------------------------------------------------------------------------------------|-----------------------------------------------------------------------|------------------------------------------------------------------|
| 固定笛卡尔阻抗控制       | u = K_p e_p + K_d e_v 或等效阻抗模型，法向通过固定刚度/阻尼表现柔顺性。            | 最容易实现；Franka/Panda 平台已有可参考实现；适合作为第三章基础基线。 | 能体现固定阻抗在变刚度接触中力误差和位置误差难兼顾。             |
| 混合力/位控制            | 切向位置控制，法向力控制或导纳力控；可用选择矩阵 S_p、S_f 分离方向。               | 实现难度低；与论文力—位协调主题最直接。                               | 能比较“显式方向分离”与合作博弈“目标加权协调”的差异。             |
| 固定 α_FP 帕累托控制     | 保持第三章控制器结构，但 α_FP 取 0.8、0.5、0.2 等固定值。                          | 已有代码改动小；可作为消融实验。                                      | 说明固定折中点无法同时适应软区、硬区和安全边界变化。             |
| MPC/QP 力—位控制         | 基于同一线性增广模型，有限时域最小化位置误差、力误差和输入，并设置力约束或软约束。 | 可用 scipy/cvxpy/OSQP；控制频率可降至 50 Hz；适合作为较强模型基线。   | 比较闭式合作博弈反馈与滚动优化在实时性、平滑性和力边界上的差异。 |
| CBF/QP 安全过滤          | 以名义控制器为输入，用接触力约束构造二次规划修正。                                 | 实现中等；适合作为仿真强安全基线，实物可选。                          | 能说明严格安全过滤与本文连续仲裁在轨迹误差和计算量上的差别。     |
| 单因素或 S 型人机仲裁    | 仅根据输入幅值、输入持续时间或力误差生成 α_HR。                                    | 实现简单；适合第四章对比。                                            | 说明只用单因素容易误接收抖动或不能区分切向/法向输入。            |
| 无安全投影的直接人类输入 | 将主端输入直接叠加到参考轨迹。                                                     | 实现最简单，但必须设置硬安全阈值。                                    | 用于证明安全参考投影和法向抑制的必要性。                         |

近年的力感知学习和安全共享自主方法可作为文献对照。ForceMimic、FORGE、FILIC
等工作说明接触丰富操作正在从纯轨迹模仿转向力—运动共同建模；Guarding
Force 等安全临界柔顺控制工作说明接触力边界可以通过 CBF/QP
进行严格约束；Barrier Pair
和多源不确定性仲裁工作说明共享自主中的人类输入不确定性和安全性需要专门处理。这些方法可放在绪论或实验讨论中，但本文实验主基线仍应选择固定阻抗、混合力/位、MPC/QP、固定优先级和单因素仲裁，因为它们最容易在当前平台上复现并与本文变量直接对齐。

# 2 实验平台与数据采集统一设置

实物实验建议复用当前已经出现过的 Franka 机械臂、Novint Falcon
主端设备、长工具和简化套管结构。柔性接触对象不需要复杂加工，可以采用硅胶片、橡胶条、泡棉垫、软质密封条或海绵—硬底板组合。为了形成可重复的分段刚度，可把两种不同硬度的材料并排固定在同一平板上，或者在同一软垫下方局部增加硬质支撑。这样可以在不新增复杂平台的条件下形成低刚度区、高刚度区和局部过渡区。

| **项目**   | **建议设置**                                                                                                                               |
|------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| 机器人平台 | Franka Emika Panda 或当前已有七自由度 Franka 机械臂。若底层接口为力矩控制，优先使用任务空间阻抗/力矩接口；若使用位置接口，可采用导纳外环。 |
| 主端输入   | Novint Falcon、手柄或脚本化输入。为了保证重复性，建议仿真和部分实物使用脚本化人类输入序列；最后补充少量真实操作者实验。                    |
| 柔性材料   | 软硅胶垫、橡胶条、泡棉或柔性密封条。低刚度区与高刚度区应固定位置，实验前用慢速压入估计表观刚度范围。                                       |
| 接触工具   | 短圆头探针用于无 RCM 任务；长工具或腹腔镜抓钳用于 RCM 任务。工具端部可加圆角或软包覆，降低实物风险。                                       |
| 力测量     | 优先使用末端六维力传感器；若没有，则使用 Franka 外力估计或关节外力矩经雅可比映射估计法向力。所有方法使用同一测量通道。                     |
| 控制频率   | 建议记录 100 Hz 数据。MPC/QP 如计算量较大，可单独标注 50 Hz 或用离线仿真比较实时性。                                                       |
| 重复次数   | 每个主要方法每个工况至少 5 次脚本化重复；真实操作者实验可每组 3 次，用作平台可行性验证。                                                   |
| 安全边界   | 接触力软边界用于评价，硬边界用于急停或卸载。所有基线必须经过同一硬安全监督层。                                                             |

数据记录应包含时间戳、末端位姿、末端速度、关节位置、关节速度、接触力、估计刚度、α_FP、α_HR、参考轨迹、实际轨迹、主端输入和控制输入。接触建立阶段不计入正式评价，可在接触力进入
\[F_min,F_max\] 并保持 1 s
后开始统计。所有图表应使用同一时间窗和同一单位，避免不同方法因截取区间不同造成误判。

# 3 第三章实验：合作博弈力—位控制器验证

第三章实验应固定人机输入，不引入复杂动态仲裁。其目的在于证明合作博弈力—位控制器能够在柔性接触中比固定阻抗、混合力/位或
MPC/QP
等基线更自然地处理位置与力的折中。实验分为仿真和实物两级。仿真用于完整比较多种基线和参数扰动；实物只保留最关键的三至四组方法，降低实验量。

| **实验**                   | **工况**                                                         | **对比方法**                                                    | **指标**                                                                              | **预期现象**                                                                        |
|----------------------------|------------------------------------------------------------------|-----------------------------------------------------------------|---------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------|
| E3-1 无 RCM 变刚度表面扫描 | 工具沿 x 方向扫描软硬分段表面，z 向保持期望接触力。无主端输入。  | 固定阻抗；混合力/位；固定 α_FP；MPC/QP；本文合作博弈动态 α_FP。 | 力 RMS、力峰值、越界时间、x/y 轨迹误差、z 向抖动、计算时间、α_FP 与 \hat K_e 相关性。 | 本文方法应在刚度切换处减少力峰值和抖动，同时轨迹误差接近固定位置优先或 MPC/QP。     |
| E3-2 RCM 长工具柔性接触    | 长工具穿过简化套管接触软垫并进行短距离扫描。无主端输入。         | 固定阻抗；混合力/位；本文合作博弈动态 α_FP；可选 MPC/QP。       | 力 RMS、力峰值、RCM RMS/峰值误差、末端误差、姿态变化、计算时间。                      | 过低位置优先会放大 RCM 误差；本文方法应在保持 RCM 合规的同时降低力越界趋势。        |
| E3-3 参数不确定性仿真      | 接触刚度估计偏差设置为 -40%、-20%、0、+20%、+40%，或加入力噪声。 | 固定 α_FP；本文动态 α_FP；CBF/QP 可选。                         | 性能随参数偏差变化曲线、越界时间、计算量。                                            | 本文方法应对中等刚度误差保持有界性能；CBF/QP 可能力边界更强但轨迹误差和计算量更大。 |

第三章实物实验建议优先完成 E3-1 和 E3-2。若时间不足，MPC/QP
可以只在仿真中实现，实物中保留固定阻抗、混合力/位和本文方法。这样仍能回答导师关于“与其他力位协调方法对比”的核心问题。论文中应客观说明，MPC/QP
作为滚动优化基线在小规模仿真中可获得较强性能，但在线求解频率、模型误差和约束软化会影响其实物表现；本文方法的优势在于闭式反馈和离线增益表便于实时执行。

# 4 第四章实验：动态人机仲裁方法验证

第四章实验应固定第三章中选定的合作博弈力—位控制器，只替换参考层人机仲裁方法。这样可以把实验差异集中到“人类输入如何进入期望轨迹”，避免控制器和仲裁器同时变化导致分析不清。

| **编号**                  | **方法**                                                          | **验证目的**                                   |
|---------------------------|-------------------------------------------------------------------|------------------------------------------------|
| A0 无人类输入             | 机器人沿名义路径扫描，操作者输入为零。                            | 验证控制器基本性能，提供参考基线。             |
| A1 直接接受输入           | x_d = x_r + K_m Δx_m，不做安全投影。                              | 展示危险法向输入会推高接触力。                 |
| A2 单因素 S 型仲裁        | α_HR 仅由输入幅值或持续时间生成。                                 | 展示单一变量难以区分切向修正、抖动和法向压入。 |
| A3 多因素仲裁但无安全投影 | 使用交互强度、持续时间和方向一致性生成 α_HR，但不投影到安全集合。 | 分离“动态权重”和“安全投影”的作用。             |
| A4 本文动态仲裁           | 多因素 α_HR + 切向/法向分解 + 安全参考投影 + 一阶滤波。           | 验证安全切向修正保留、危险法向压入抑制。       |

| **工况**                | **输入设计**                                               | **预期观察**                                                                   |
|-------------------------|------------------------------------------------------------|--------------------------------------------------------------------------------|
| S1 安全切向修正         | 操作者在扫描中给出横向偏移，绕开标记区域或覆盖感兴趣区域。 | α_HR 应平滑升高；x_d^I 沿切向偏移；接触力不出现明显上界越界。                  |
| S2 短时扰动             | 给出 0.2–0.5 s 的小幅随机输入或反向输入。                  | 滤波和持续时间特征应抑制 α_HR 突跳；轨迹和力曲线不出现大峰值。                 |
| S3 不安全法向压入       | 操作者沿接触法向继续压入。                                 | 安全投影削弱法向参考；ρ_F 下降后执行层降低位置优先级或增强卸载；越界时间减少。 |
| S4 目标重定向或大幅修正 | 持续输入引导机器人去新的扫描带。                           | α_HR 上升并保持；轨迹平滑转移；若新参考会造成力越界，则只保留安全部分。        |

第四章的关键图建议包括四类：α_HR 与人类输入特征的时序图；x-y
平面轨迹图，展示切向修正是否进入最终轨迹；法向输入局部放大图，展示安全投影前后的参考差异；接触力时序图，展示直接接受输入与本文方法在力峰值和越界时间上的差别。

# 5 第五章实验：综合验证方案

第五章应把第三章控制器和第四章仲裁器组合起来，在统一平台上验证完整闭环。建议设置两个主实验任务，分别对应无
RCM 的工业柔性表面操作和带 RCM
的长工具柔性接触操作。这样既回应导师关于“总体定位不局限于手术或工业”的意见，也能利用现有平台，不需要搭建复杂新系统。

| **任务**                    | **平台设置**                                                                   | **验证重点**                                                           |
|-----------------------------|--------------------------------------------------------------------------------|------------------------------------------------------------------------|
| T1 无 RCM 柔性表面检测/扫描 | 短探针接触橡胶条或硅胶垫，沿表面扫描。材料上标出需要绕开的缺陷区或额外覆盖区。 | 验证工业柔性接触任务中的切向人类修正、变刚度接触和力边界保护。         |
| T2 RCM 长工具柔性接触扫描   | 长工具通过简化套管接触软垫或仿组织材料，完成短路径扫描或点到点接触。           | 验证同一方法在固定点—轴线几何约束下是否仍能保持 RCM 误差和接触力安全。 |

| **方法**            | **配置**                                               | **作用**                                      |
|---------------------|--------------------------------------------------------|-----------------------------------------------|
| B1 固定参数直接输入 | 固定 α_FP=0.5，直接接受人类输入。                      | 最弱但直观的工程基线。                        |
| B2 仅第三章控制器   | 动态 α_FP 或合作博弈控制器启用，但不接受人类修正。     | 验证缺少人类修正时任务覆盖不足。              |
| B3 仅第四章仲裁     | 安全人机仲裁启用，但执行层为固定混合力/位或固定 α_FP。 | 验证缺少动态力—位执行调度时力越界仍可能较多。 |
| B4 完整方法         | 第三章合作博弈控制器 + 第四章动态人机仲裁。            | 验证两层组合的综合效果。                      |

| **指标类别**     | **具体指标**                                                                    | **物理意义**                                         |
|------------------|---------------------------------------------------------------------------------|------------------------------------------------------|
| 力安全           | \$E_F^{RMS}\$、\$\|e_F\|\_{max}\$、\$T\_{vio}\$、力抖动 \$J_F\$                 | 说明接触是否稳定，是否接近或越过安全边界。           |
| 轨迹质量         | \$E_x^{RMS}\$、切向偏移跟随误差、任务覆盖率、jerk                               | 说明机器人是否完成扫描或绕行任务，运动是否平滑。     |
| 人机协同         | \$R\_{acc}\$ 安全切向修正接受率、\$R\_{sup}\$ 危险法向输入抑制率、α_HR 响应时间 | 说明人类经验是否被合理接受，危险输入是否被削弱。     |
| 几何约束         | \$e\_{gc}^{RMS}\$、\$e\_{gc}^{max}\$、工具轴线姿态误差                          | 仅用于 RCM 或固定点—轴线任务，说明长工具通道合规性。 |
| 实时性与控制代价 | 平均计算时间、最大计算时间、关节力矩峰值、控制输入 RMS                          | 说明方法是否适合固定控制周期和硬件执行。             |

第五章结果分析建议采用“总体统计—典型时序—局部放大—综合讨论”的顺序。先用一张统计表给出四种方法在
T1 和 T2 中的均值和标准差，再用接触力/α_FP/α_HR
时序解释动态权重变化，随后用轨迹图展示安全切向修正是否被保留，最后用法向压入局部放大图说明安全投影和执行层力调节共同作用。若完整方法在某一单项指标上不是最优，应如实说明。例如，强力优先可能获得更小力
RMS，但其任务覆盖率和人类修正接受率较低；固定高位置优先可能轨迹误差更小，但力越界时间更长。

# 6 实验实施步骤与最小工作量版本

为降低补实验风险，建议先完成最小闭环版本，再扩展到完整对比。最小版本不追求覆盖所有文献方法，而是保证每章都有能支撑结论的核心数据。

| **步骤** | **内容**                                                                         | **输出**                       |
|----------|----------------------------------------------------------------------------------|--------------------------------|
| 第 1 步  | 整理仿真脚本，统一输入序列、材料刚度、采样频率和指标计算函数。                   | 得到所有方法可复用的评价框架。 |
| 第 2 步  | 完成第三章无 RCM 仿真对比：固定阻抗、混合力/位、固定 α_FP、本文方法。            | 确认控制器趋势正确。           |
| 第 3 步  | 搭建无 RCM 软垫扫描实物实验，只做固定阻抗、混合力/位、本文方法三组。             | 获得第三章实物结果。           |
| 第 4 步  | 在同一实物任务中加入脚本化切向修正和法向压入，比较直接输入、S 型仲裁、本文仲裁。 | 获得第四章实物结果。           |
| 第 5 步  | 将长工具和简化套管加入平台，完成 RCM 任务中固定参数与完整方法对比。              | 获得第五章综合实物结果。       |
| 第 6 步  | 补充参数敏感性仿真和少量实物重复，形成均值±标准差表。                            | 增强论文可信度。               |

*最小可交付实验组合：第三章仿真 4 组方法 + 第三章无 RCM 实物 3
组方法；第四章实物 3 组仲裁方法；第五章 RCM 综合实物 2
组方法。若时间允许，再增加 MPC/QP、CBF/QP 和更多重复次数。*

图表分析时应先说明实验设置和预期观察对象，再给出数据现象，最后回扣方法设计。比如分析
α_FP 时，不应只写“α_FP
随刚度变化”，而应说明在高刚度区同样的位移误差会产生更大接触力，控制器因此降低或提高某一优先级以抑制风险。若符号方向在第三章和第五章不同，必须统一后再写，否则读者会混淆。

# 9 预期结论边界

实验结论应保持克制。建议写成：结果表明，在所设置的柔性接触扫描和长工具约束接触工况下，所提合作博弈力—位控制器能够在力安全和轨迹精度之间取得较稳定的综合折中；动态人机仲裁能够在保留安全切向修正的同时抑制危险法向输入；完整方法在综合指标上优于固定参数和单一仲裁方法。不要写“全面优于所有方法”或“彻底解决柔性接触操作问题”。

若某些结果不完全符合预期，也可以转化为合理讨论。例如，固定强力优先可能在某些软区获得最小力误差，但轨迹覆盖变差；MPC/QP
可能在仿真中具有较好约束效果，但实物实时性和模型失配更敏感；CBF/QP
可能力边界更严格，但控制输入不连续或轨迹保守。这样的讨论比单纯追求所有指标第一更符合控制科学论文写法。


## 4. 第 5.1 节：综合验证目标

本节需要回答三个问题：为什么需要第五章，验证什么，如何判断验证成立。建议第一段从前文方法组合切入：第三章已给出执行层力位协同控制器，第四章已给出参考层动态仲裁方法；真实柔性接触操作中，操作者输入、环境刚度变化、接触力边界和几何约束往往同时存在，因此有必要在统一系统中考察两类模块的兼容性和综合效果。

建议本节设置四个验证问题。

| 验证问题 | 对应实验现象 | 主要指标 |
| --- | --- | --- |
| 执行层控制器是否能处理柔性接触中的力位耦合 | 变刚度区域内力越界时间下降，轨迹误差保持可接受 | 力均方根误差、力越界时间、轨迹均方根误差 |
| 参考层仲裁是否能处理人类输入差异 | 安全切向修正被接受，危险法向压入被削弱 | 人类修正接受率、危险输入抑制率、接触力峰值 |

| 方法是否适用于不同边界条件 | 无远心运动约束任务和带远心运动约束任务均有可解释结果 | 接触指标、轨迹指标、几何约束误差 |

建议正文中谨慎表述本章结论。可以写“在所设工况下，完整组合方法在综合指标上优于固定参数和单层方法”，不宜写“全面优于所有方法”。若某个基线在单项力误差或位置误差上更好，应如实说明，并解释本文目标是力安全、轨迹覆盖、人类修正和实时性的综合折中。

## 6. 第 5.3 节：综合评价体系

本节建议先给对比方法，再给评价指标。评价指标必须在图表前定义，避免结果分析时临时解释符号。

### 6.1 对比方法

对比方法分为固定参数基线、单层模块消融和完整组合方法三类。建议使用中文代号，不使用英文固定比例代号。

| 中文代号 | 参考层设置 | 执行层设置 | 验证目的 |
| --- | --- | --- | --- |
| 强位置优先 | 固定接受人类输入 | 固定较高力位优先级 | 检验位置优先过强时的力安全风险 |
| 均衡优先 | 固定接受人类输入 | 固定中等力位优先级 | 检验人工折中基线 |
| 强力优先 | 固定接受人类输入 | 固定较低力位优先级 | 检验力调节过强时的轨迹覆盖损失 |
| 仅参考层仲裁 | 启用第四章动态仲裁 | 固定中等力位优先级 | 检验缺少执行层动态力位调节的影响 |

### 6.2 评价指标

力安全指标建议包括：

```tex
E_F^{\mathrm{RMS}}=
\sqrt{\frac{1}{N}\sum_{k=1}^{N}\left(y_{f,k}-F_d\right)^2},
```

```tex
T_{\mathrm{vio}}=
T_s\sum_{k=1}^{N}\mathbb I\left(y_{f,k}<F_{\min}\ \mathrm{or}\ y_{f,k}>F_{\max}\right),
```

其中 `E_F^{RMS}` 表示法向接触力相对期望力的均方根误差，用于衡量接触力调节精度；`T_vio` 表示接触力超出安全区间的累计时间，比单纯越界次数更适合和实验持续时间对应。

轨迹质量指标建议包括：

```tex
E_x^{\mathrm{RMS}}=
\sqrt{\frac{1}{N}\sum_{k=1}^{N}\left\|x_k-x_{d,k}\right\|^2},
```

```tex
J_x=
\sqrt{\frac{1}{N}\sum_{k=1}^{N}\left\|\dddot x_k\right\|^2}.
```

其中 `E_x^{RMS}` 衡量末端实际轨迹对最终期望轨迹的跟踪误差；`J_x` 表示任务空间 jerk，用于反映运动平滑性。实物实验中若三阶差分噪声较大，可只在滤波后数据上计算，并在正文说明。

人机协同指标建议包括：

```tex
R_{\mathrm{acc}}=
\frac{\sum_{k\in\mathcal K_T}\left\|x_{d,k}-x_{r,k}\right\|}
{\sum_{k\in\mathcal K_T}\left\|x_{h,k}-x_{r,k}\right\|+\varepsilon},
```

```tex
R_{\mathrm{sup}}=
1-
\frac{\sum_{k\in\mathcal K_N}\max\{d_{d,k}^{N},0\}}
{\sum_{k\in\mathcal K_N}\max\{d_{h,k}^{N},0\}+\varepsilon}.
```

其中 `\mathcal K_T` 表示安全切向修正时间段，`R_acc` 描述操作者安全修正被最终期望轨迹接受的比例；`\mathcal K_N` 表示危险法向输入时间段，`d_h^N` 和 `d_d^N` 分别表示人侧候选参考和最终期望轨迹中的法向压入量，`R_sup` 描述危险输入被削弱的比例。该指标只在预先设置的切向修正段或法向误推段计算，不用于全部时间。

远心运动约束指标建议用于长工具实验：

```tex
E_{\mathrm{gc}}^{\mathrm{RMS}}=
\sqrt{\frac{1}{N}\sum_{k=1}^{N}e_{\mathrm{gc},k}^{2}},
\quad
E_{\mathrm{gc}}^{\max}=\max_k e_{\mathrm{gc},k}.
```

其中 `e_gc` 表示固定点到工具轴线的几何距离，用于衡量长工具操作是否满足远心运动边界。该指标只在带远心运动约束的实验中作为补充指标，不作为全文核心问题。

综合评分只用于同一工况内部比较。建议使用归一化指标：

```tex
S=
w_F\tilde E_F+
w_V\tilde T_{\mathrm{vio}}+
w_X\tilde E_x+
w_A(1-R_{\mathrm{acc}})+
w_S(1-R_{\mathrm{sup}})+
w_C\tilde T_{\mathrm{comp}},
```

若包含长工具实验，可增加 `w_G\tilde E_gc`。权重应在实验前固定，并在论文表格中给出。综合评分用于帮助读者理解多指标折中，不能替代各单项指标分析。

## 7. 第 5.4 节：综合仿真验证

综合仿真建议主要复用原第五章已有结果，并按当前章节定位重写。仿真部分承担两个功能：一是进行比实物更完整的消融和参数敏感性分析；二是解释为什么完整组合方法在多因素耦合工况中更稳定。

### 7.1 仿真工况

建议设置三个仿真工况。

| 工况 | 任务内容 | 主要验证点 |
| --- | --- | --- |
| 表面扫描工况 | 工具沿柔性表面扫描，材料包含软区、硬区和局部缺陷区域 | 验证变刚度下的力位调节和切向修正接受能力 |
| 危险输入工况 | 操作者给出安全切向修正、持续目标重定向、短时扰动和危险法向压入 | 验证参考层仲裁对输入类型的区分能力 |
| 长工具工况 | 工具通过固定孔或虚拟远心运动点接触柔性材料 | 验证组合方法在几何边界条件下的可执行性 |

原第五章已有的柔性工件表面接触式扫描仿真可作为第一和第二类工况的主体。建议保留其中的分段刚度设置：低刚度区、高刚度区、局部缺陷区和名义刚度不匹配。该设置能主动暴露固定参数方法的局限。

| 均衡优先 | 8.386 | 0.317 N | 4.50 s | 2.52 mm | 0.58 | 0.42 |
| 强力优先 | 4.735 | 0.204 N | 1.54 s | 2.49 mm | 0.58 | 0.42 |
| 仅参考层仲裁 | 8.001 | 0.315 N | 4.50 s | 1.74 mm | 0.89 | 0.91 |
| 仅执行层调节 | 4.320 | 0.235 N | 1.52 s | 5.63 mm | 0.00 | 1.00 |
| 完整组合方法 | 3.843 | 0.230 N | 1.48 s | 1.74 mm | 0.89 | 0.93 |

分析时应避免只说“完整方法最好”。更有说服力的写法是：强力优先在力均方根误差上略低，但其人类修正接受率和危险输入抑制率较弱；仅执行层调节能降低力越界，却无法接受操作者安全切向修正；仅参考层仲裁能保留人类修正，但缺少动态力位调节，高刚度区仍存在越界。完整组合方法在综合评分上最低，说明两层模块在所设工况下形成了更均衡的折中。

## 8. 第 5.5 节：表面操作实验

本节建议作为无远心运动约束实物实验，目标是证明本文方法不依赖手术或长工具平台，也适用于一般柔性表面接触操作。该实验改动小、可测量、预期效果明确，适合作为第五章实物验证的第一组。

### 8.1 实验设置

建议使用 Franka 机械臂末端安装圆头探针或短杆，柔性材料采用海绵、硅胶块或泡棉，并用不同硬度材料拼接形成软区和硬区。机器人执行一条直线或轻微曲线扫描路径，期望接触力取 `0.5-1.0 N` 范围内的安全值。操作者通过主端设备在两类时间段输入指令：一类为沿表面切向的安全修正，用于绕开标记区域或扩大覆盖；另一类为沿接触法向的危险压入，用于检验安全投影和力位优先级调节。

建议重复次数和对比如下。

| 项目 | 建议设置 |
| --- | --- |
| 重复次数 | 每组方法 3 次，条件允许时 5 次 |
| 对比方法 | 均衡优先、仅参考层仲裁、仅执行层调节、完整组合方法 |
| 采样频率 | 控制和记录均不低于 100 Hz |
| 接触力阈值 | 按材料安全范围设置，例如 `F_min=0.3 N, F_d=0.7 N, F_max=1.2 N` |
| 安全停止 | 设硬阈值 `F_hard`，超过后停止推进并记录事件 |

该实验的优点是无需额外复杂平台，只要固定柔性材料并保证末端工具圆滑即可完成。若主端设备暂时不可用，可以先用预设人类输入序列完成可重复实验，再在后续补充真实操作者输入。

### 8.2 预期现象

表面操作实验预期出现以下结果。

| 方法 | 预期表现 | 分析落点 |
| --- | --- | --- |
| 均衡优先 | 能跟随部分人类输入，但高刚度区力峰值较明显 | 固定优先级无法适应材料变化 |
| 仅参考层仲裁 | 能接受安全切向修正，危险输入阶段仍依赖固定执行层 | 参考层有效但执行层不足 |
| 仅执行层调节 | 力越界时间较低，轨迹更接近自主路径 | 执行层有效但缺少人类监督 |
| 完整组合方法 | 切向修正接受率高，危险法向输入影响小，综合评分较低 | 两层模块互补 |

正式论文中可将实物结果写成：完整组合方法在保证力安全的同时保留操作者对轨迹的有效修正，说明参考层和执行层在实物柔性表面操作中具有兼容性。若某组固定方法的力误差较小，应说明其代价是轨迹覆盖或人类修正接受能力下降。

## 9. 第 5.6 节：长工具操作实验

本节建议作为带远心运动约束的长工具实物实验，用于回应导师关于手术场景、远心运动边界和章节定位的意见。该实验应写成柔性接触操作的一种边界条件，而不是全文唯一主场景。

### 9.1 实验设置

建议采用长工具通过固定孔、套管或简化支点接触柔性材料。固定孔中心作为远心运动点，工具轴线由法兰位姿和工具几何计算得到。机器人执行短距离扫描或轻触压入任务，操作者给出切向修正和法向误推。任务长度建议控制在 `30-60 s`，路径短而稳定，避免过多引入视觉识别、复杂曲面建模或手术器械夹持问题。

建议设置如下。

| 项目 | 建议设置 |
| --- | --- |
| 工具 | 长杆、腹腔镜等效工具或现有长工具末端 |
| 固定结构 | 3D 打印套管、固定孔或刚性夹具 |
| 柔性对象 | 硅胶块、泡棉或软质板材 |
| 任务 | 通过固定点接触柔性表面并沿短路径扫描 |
| 对比方法 | 均衡优先、仅执行层调节、完整组合方法 |
| 主要指标 | 接触力指标、轨迹指标、远心运动误差、人类修正指标 |

长工具实验不宜过复杂。重点是证明完整组合方法在带几何边界时仍能执行，并在危险法向输入下减少力峰值，同时不显著增大远心运动误差。若套管摩擦或工具柔顺性带来额外误差，应在正文中说明其工程影响。

### 9.2 远心运动误差计算

建议在正文中简要给出远心运动约束误差。设固定点为 `p_r`，工具轴线上一点为 `p_t`，单位方向为 `a_t`，则固定点到工具轴线的距离为：

```tex
e_{\mathrm{gc}}=
\left\|
\left(I-a_ta_t^{\mathrm T}\right)(p_r-p_t)
\right\|.
```

该指标具有明确几何意义：若固定点位于工具轴线上，则误差为零；误差越大，说明工具轴线偏离固定点越明显。正文中应说明远心运动误差在本章是长工具实验的约束指标，力位协同和人机仲裁仍是主要研究对象。

### 9.3 预期现象

长工具实验预期出现以下结果。

| 现象 | 解释 |
| --- | --- |
| 完整组合方法的力峰值低于均衡优先 | 安全投影削弱危险法向参考，执行层在力裕度降低时增强力调节 |
| 完整组合方法的切向修正可进入轨迹 | 参考层动态仲裁保留安全人类输入 |
| 远心运动误差没有明显上升 | 工具几何边界由约束映射和速度限幅保证 |
| 仅执行层调节的轨迹偏向自主路径 | 缺少参考层人机仲裁，操作者安全修正难以进入任务 |

若实物实验中远心运动误差受套管间隙影响较大，建议将结果写为“完整组合方法未显著恶化几何约束误差”，避免承诺高精度远心运动控制。

## 10. 第 5.7 节：敏感性分析

参数敏感性建议主要在仿真中完成，实物实验只做少量验证。这样既能回应导师意见，也能控制实验工作量。

### 10.1 参数选择

建议只选 4 类关键参数。

| 参数 | 三档设置 | 观察指标 | 预期趋势 |
| --- | --- | --- | --- |
| 执行层优先级下限 | 低、中、高 | 力越界时间、轨迹误差 | 下限过高导致力峰值增大，下限过低导致轨迹滞后 |
| 执行层滤波速度 | 慢、中、快 | 力抖动、优先级变化率 | 过慢响应滞后，过快引入抖动 |
| 人机仲裁滤波速度 | 慢、中、快 | 接受率、参考平滑性 | 过慢使人类修正迟滞，过快放大手部抖动 |
| 接触力安全余量 | 小、中、大 | 抑制率、路径覆盖率 | 余量过小保护不足，余量过大使系统保守 |

正式实验中可先用仿真筛选中档参数，再在实物上选择两个参数做三档重复。例如只对安全余量和人机仲裁滤波速度进行实物敏感性验证，每档重复 3 次。

### 10.2 消融实验

建议设置以下消融方法。

| 消融方法 | 去除模块 | 预期结果 |
| --- | --- | --- |
| 无安全投影 | 关闭人侧参考安全投影 | 危险法向输入阶段接触力峰值上升 |
| 固定执行层优先级 | 关闭动态力位调节 | 变刚度区越界时间增加或轨迹质量下降 |
| 固定人机权重 | 关闭动态人机仲裁 | 切向修正接受不充分，短时扰动更容易进入轨迹 |
| 无完整组合 | 同时固定两层参数 | 综合评分下降，现象解释性较弱 |

消融结果应和第三章、第四章贡献相互对应。固定执行层优先级对应第三章模块的作用；固定人机权重和无安全投影对应第四章模块的作用；完整组合方法对应第五章综合验证。

## 11. 正文写作逻辑

第五章正式正文建议按照“设置、指标、结果、原因、边界”的顺序展开。

第一，先说明实验目的和平台，避免一上来进入大量公式。第五章公式以评价指标和几何误差为主，控制律推导回到第三章和第四章。这样读者能清楚知道本章是验证章。

第二，图表前必须有文字介绍。每张图或表之前先说明实验工况、比较对象和主要观察结果；图表之后再解释原因、支撑哪一个设计点。图片与正文应形成前后照应，图后分析需要落到具体指标和方法机理上。

第三，分析需要承认单项指标差异。强力优先可能在力均方根误差上较好，完整组合方法的优势在综合评分、人类修正接受、危险输入抑制和跨工况稳定性。这样写比单纯宣称“本文方法最优”更严谨。

第四，术语必须统一。正文中使用“力位协同控制”“力位优先级”“人机仲裁权重”“远心运动约束”，避免使用带斜杠的中文名词。`MPC`、`QP` 等英文缩写若必须出现，应写成“模型预测控制”和“二次规划安全控制”。

第五，实物实验中不要提具体实现文件、数据路径和处理程序名称。可写“根据记录数据计算各项指标”“实验结果见表”，不写数据保存路径。

## 12. 最小可交付实验方案

若时间紧张，建议采用以下最小闭环方案。

| 优先级 | 实验 | 最少分组 | 最少重复 | 必须产出 |
| --- | --- | --- | --- | --- |
| 最高 | 综合仿真 | 六组方法 | 每组一次可重复仿真 | 统计表、柱状图、时序图 |
| 最高 | 表面操作实物 | 均衡优先、仅执行层调节、完整组合方法 | 每组 3 次 | 力曲线、轨迹图、统计表 |
| 高 | 长工具实物 | 均衡优先、完整组合方法 | 每组 3 次 | 平台照片、力曲线、远心运动误差 |
| 中 | 参数敏感性仿真 | 四类参数三档 | 每档一次或三次 | 热图或折线图 |
| 中 | 消融仿真 | 无安全投影、固定两层参数、完整组合方法 | 每组一次或三次 | 消融柱状图 |

该方案改动小，不需要额外搭建复杂平台，且每个实验都有明确预期现象。表面操作实验证明方法具有一般柔性接触适用性；长工具实验回应远心运动和手术类边界条件；综合仿真负责展示完整消融和参数敏感性。

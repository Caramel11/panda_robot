# 1 总体定位与全文主线

导师意见中“手术还是工业”的问题，本质上不是要求在两个应用场景中二选一，而是要求论文给出更高层次的研究对象。建议将全文定位为“面向人机协同柔性接触操作的力—位协调控制”。在这一定位下，机器人辅助手术训练、长工具远心运动任务、柔性密封条检测、复合材料打磨、软质工件扫描等均为典型实例。它们的差异主要体现在工具、工件和评价边界上，共同控制问题是人在环修正、机器人自主执行、柔性接触力安全和位置轨迹精度之间的协调。

全文的技术主线应从“控制问题”自然推进，而不是从“应用场景”并列展开。第一层问题是柔性接触任务中位置误差和接触力误差相互耦合，需要一个能够解释力—位权衡的执行层控制器。第二层问题是人类在线修正对任务有价值，但输入中同时包含有效切向修正、短时扰动和危险法向压入，需要一个能够筛选和仲裁人类影响的参考层方法。第三层问题是上述两个层次在真实任务中同时出现，因此需要综合实验验证二者的兼容性、实时性和工程边界。

当前 LaTeX 主文件仍按六章组织，章节输入顺序为 abstract、chapter1 至
chapter6，文献库位于
refs/references。结构上已经接近硕士论文常规框架，但题名、第三至第五章定位与导师意见存在明显错位。ustcsetup.tex

第一章已经尝试把工业柔性任务和机器人辅助手术放在同一背景下讨论，并列举了接触力上下界、固定点—轴线约束和典型工业任务。这些内容可以保留，但应收敛表达。当前第一章开头仍把后续章节描述为第三章刚性几何约束、第四章柔性接触、第五章工业双仲裁，容易形成“手术—工业—综合”的横向拼接感。修改后应把第三章改写为力—位协同控制方法，把第四章改写为人机动态仲裁方法，把第五章改写为综合实验验证。

第二章已经包含机器人运动学、动力学、几何约束、阻抗控制、接触模型、LQR、微分博弈和稳定性分析。其优点是符号较完整，缺点是通识内容偏多，部分稳定性与鲁棒性工具在方法章节中会再次出现。导师提出“缺少参考文献、加阻抗控制、2.4是否有必要”，说明第二章应从“百科式预备知识”转为“后续章节必需的理论接口”。阻抗控制和柔性接触模型应保留并加强，泛泛的非线性稳定性和扰动讨论可压缩为后续证明所需的简短引理。

第三章当前题名为“面向刚性约束操作场景的意图驱动合作微分博弈共享控制方法”，章节内容主要处理远心运动或固定点—轴线约束下的人机共享控制。该写法与新的第三章题名不一致。新的第三章应承担执行层核心控制器的证明和实验，即说明合作博弈如何实现柔性接触中的力—位协同，而不是继续围绕人机意图仲裁或刚性几何约束展开。现有第三章中的人机仲裁、目标切换和
RCM 实验可迁移到第四章或第五章。

第四章当前已经包含折扣帕累托力—位协同控制、环境刚度估计、力安全裕度仲裁、离线增益表、理论分析和仿真。该章的技术内容更适合成为新的第三章主体。需要补强的是与阻抗控制、混合力/位控制、MPC/QP
等基线方法的对比，以及至少一组简化实物实验。第四章新题名为“面向人机协同柔性操作的动态仲裁方法”后，不应继续以力—位控制器为主，而应转向人类输入动态仲裁、安全投影和切向/法向输入筛选。

第五章当前题名为“面向工业约束接触任务的双仲裁合作博弈控制方法”，章节中建立了新的任务模型、参考层安全投影、执行层力—位仲裁、折扣黎卡提反馈和理论分析。导师意见指出第五章的技术贡献、预期现象、分析逻辑和实物实验需要重新界定。建议将第五章改为综合实验验证章，不再提出新的完整理论框架。该章可以保留双仲裁思想，但应以实验平台、工况、对比方法、指标定义、结果和分析为主体。

# 4 第一章修改方案

第一章应承担统一研究对象和全文逻辑的任务。当前第一章的材料较丰富，但应用背景、相关研究和章节关系之间的重心不够集中。建议把第一章标题保持为“绪论”，内部结构调整为“研究背景及意义、国内外研究现状、本文研究内容与创新点、全文组织结构”。其中，研究背景不要分别写成手术一条线、工业一条线，而应先提出柔性接触操作的共性控制矛盾，再以手术和工业作为例证。

| **小节**           | **修改要求**                                                                                                                                                                                           |
|--------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1.1 研究背景及意义 | 压缩应用铺陈。先写柔性接触操作的共性：位置轨迹决定任务覆盖，法向接触力决定安全和质量，人类修正提供经验但可能引入力风险。随后各用一段说明工业和手术训练的代表性。                                       |

| 1.2.4 的处理       | 若当前 1.2.4 只是单独列出手术或工业应用，建议并入前面各小节或改为“典型应用中的共性需求”。应用综述不宜成为独立大篇幅，否则会削弱控制方法主线。                                                          |
| 1.3 本文研究内容   | 按第三、四、五章重新写。第一项是合作博弈力—位协同控制；第二项是面向人机协同的动态仲裁与安全参考生成；第三项是综合仿真和实物验证。                                                                      |

RCM 任务和普通表面接触任务，是为了覆盖有无几何约束两种典型边界。

# 6 第三章修改方案：合作博弈力—位协同控制

新的第三章题名为“基于合作博弈的柔性接触力-位协同控制方法”。本章应成为全文控制方法的核心，主要回答柔性接触任务中位置跟踪与接触力调节如何在同一反馈律中形成可解释折中。人类输入和动态人机仲裁不是本章主角，可在背景中说明其为后续第四章提供接口。

| **小节内容**     | **修改要求**                                                                                                                                                                   |
|------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 章首过渡         | 由第一、二章自然引出：柔性接触操作中，固定位置控制会造成力峰值，单纯力控会牺牲轨迹覆盖，因此需要统一的力—位增广模型和可调优先级。不要再以刚性几何约束或 RCM 作为本章第一句话。 |
| 问题描述         | 定义接触点位置 x、期望轨迹 x_d、接触力 y_f、期望力 F_d、安全边界 \[F_min,F_max\]。说明本章目标是在模型误差和变刚度条件下同时降低位置误差、力误差和力越界风险。                 |
| 系统建模         | 采用修正阻抗动力学和 Kelvin–Voigt 局部接触模型，构造 ξ=\[e_p,e_v,e_f,σ_f\]^T。环境刚度估计可保留为增益调度变量，但不宜把估计器写成章节主要贡献。                               |
| 合作博弈控制器   | 将位置目标和力目标看作两个合作参与方，定义 J_p 和 J_f，利用 α_FP 进行帕累托标量化，求解折扣 ARE 得到 u=-K(α_FP,\hat K_e)ξ。                                                    |
| 安全裕度与优先级 | ρ_F 用于描述接触力距离上下界的剩余空间。α_FP 的物理含义要稳定：数值大时偏位置，数值小时偏力调节；如采用方向性修正，必须与后续实验现象一致。                                    |
| 理论分析         | 保留固定 α_FP 下最优性和闭环稳定性；保留残差扰动下有界性能；保留慢变 α_FP 下的性能损失或稳定性条件。证明用语应围绕公式展开，避免过多解释性口号。                               |
| 实验验证         | 本章至少包含仿真和简化实物实验。对比对象建议为固定阻抗、混合力/位控制、MPC/QP 或固定 α_FP。重点展示合作博弈方法在力误差、轨迹误差、力越界时间和实时性之间的综合折中。          |

第三章的贡献可以表述为：在柔性接触操作任务中，建立包含位置误差、接触力误差和力误差积分的增广系统；将位置目标与力目标构造成合作博弈或折扣帕累托最优控制问题；通过可调力—位优先级获得闭式反馈律或离线增益表；在变刚度和力安全边界下验证该控制律相对于固定参数方法的折中优势。这里的贡献重心是控制器设计和力—位协调，不是模糊仲裁。

# 7 第四章修改方案：人机协同动态仲裁

新的第四章题名为“面向人机协同柔性操作的动态仲裁方法”。本章不应重复第三章控制器推导，而应说明在人类参与时，怎样判断输入是否应被接受，怎样区分切向有效修正和法向危险压入，怎样使人类意图以平滑、可解释和安全的方式进入期望轨迹。

| **小节内容** | **修改要求**                                                                                                                                   |
|--------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| 章首过渡     | 从第三章控制器的局限引出：即使执行层能协调力和位置，机器人仍需要处理操作者在线修正。人的输入既可能改善轨迹覆盖，也可能破坏接触力安全。         |
| 人类输入特征 | 定义主端位移、速度、交互力、输入持续时间、方向一致性、空间风险等特征。解释每个特征对应的物理现象，不要把模糊规则写成独立炫技内容。             |
| 参考层融合   | 保留 β 或 α_HR 的作用边界。β 可用于直接遥操作参考与自主参考的低层融合，α_HR 用于人侧安全参考与自主参考的权重。若保留二者，必须在章首说明差异。 |
| 安全参考投影 | 引入局部接触力预测和安全参考集合，将人侧参考投影到力边界和几何约束允许的集合内。突出该步骤能削弱危险法向输入，同时尽量保留切向修正。           |
| 动态仲裁律   | 可采用双通道模糊、S 型映射加滤波或基于安全裕度的规则，但贡献应写成“面向柔性接触人机协同的动态仲裁机制”，而不是单纯“设计了模糊控制器”。         |
| 理论性质     | 给出 α_HR 区间不变性、变化率有界性、安全投影有界性，以及由有界参考输入引起的闭环有界性说明。不要过度声称严格安全，硬安全监督可作为工程边界。   |
| 实验验证     | 固定第三章控制器，只替换人机仲裁策略。比较直接接受、S 型/单因素仲裁、无安全投影和本文仲裁。场景包括安全切向修正、短时扰动、不安全法向压入。    |

第四章的核心贡献可以表述为：在柔性接触操作中构造参考层动态仲裁方法，使操作者的安全切向修正能够进入期望轨迹，同时利用安全投影和力安全裕度抑制可能造成接触力越界的法向输入。该贡献与第三章的执行层控制器互补，二者分别作用于参考生成和反馈执行。

# 8 第五章修改方案：综合实验验证

第五章的新题名为“人机协同柔性物体操作综合实验验证”。本章应从方法章转为实验章，主要任务是把第三章的合作博弈力—位控制器和第四章的人机动态仲裁方法放到同一平台上验证。导师关注的“第五章技术贡献”应转化为“综合验证贡献”：通过统一平台、统一指标和多工况实验说明前两章方法组合后具有可执行性和可解释性。

| **内容模块** | **修改要求**                                                                                                                                           |
|--------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| 实验平台     | 说明机器人、主端设备、末端接触工具、柔性材料、力测量方式、控制频率、采样频率、重复次数和安全阈值。该部分要具体，不能只写“进行仿真验证”。               |
| 实验任务     | 建议设置无 RCM 的柔性表面扫描任务和带 RCM 的长工具柔性接触任务。工业和手术不作为论文定位的二选一，而作为两个典型边界条件。                             |
| 对比方法     | 围绕结构消融设置：固定参数控制、仅力—位控制、仅人机仲裁、完整方法。对第三章基线可补充阻抗、混合力/位和 MPC/QP。                                        |
| 评价指标     | 力 RMS、力峰值、越界时间、位置 RMS、RCM 误差、jerk、控制输入、计算时间、人类意图接受率、危险输入抑制率。每个指标先定义，再解释物理意义。               |
| 预期现象     | 安全切向修正应被接受，危险法向压入应被抑制；刚度升高或力裕度下降时 α_FP 应向力调节方向移动；人类持续明确干预时 α_HR 应平滑上升；短时扰动不应造成突变。 |
| 结果组织     | 先给总体统计表，再分别分析力安全、轨迹覆盖、人机输入处理、RCM 合规和实时性。不要只展示最有利图，也要说明单项指标非最优时的原因。                       |

第五章不宜继续写成“提出一种双仲裁合作博弈控制方法”。如果保留双仲裁一词，建议在章首说明它是第三章和第四章方法在实验中的组合形式。理论分析可压缩为“实验方法与安全监督”，将空间留给平台、工况、参数、数据和讨论。

# 9 摘要、结论和符号系统同步修改

摘要需要随全文重排同步改写。中文摘要建议采用四段式：研究背景与问题、第三章方法、第四章方法、第五章实验结论。摘要中不要继续强调“刚性几何约束任务”作为第三章对象，也不要把第五章写成另一个理论方法。英文摘要中的
constrained manipulation 可保留为 broader
context，但题名和正文关键词应体现 flexible contact manipulation 和
human-robot collaborative operation。

结论章需要对应新的章节关系。第三章总结合作博弈力—位协同控制，第四章总结人机动态仲裁，第五章总结综合实验验证。当前总结中关于“当前实验主要围绕可控仿真环境”的不足表述，需要在补充实物实验后改为更准确的边界，例如真实工件种类、长期磨损、更多被试和复杂曲面的不足。

| **符号** | **统一要求**                                                                                                                   |
|----------|--------------------------------------------------------------------------------------------------------------------------------|
| α_HR     | 只表示参考层人机仲裁权重。不得在第三章用作力—位优先级。                                                                        |
| β        | 可表示直接遥操作参考与自主参考的融合系数。若与 α_HR 同时存在，应说明 β 是参考生成内部变量，α_HR 是人侧参考影响最终轨迹的权重。 |
| α_FP     | 只表示执行层位置目标与力目标的优先级。建议明确“数值大偏位置，数值小偏力调节”，并保持全文章节一致。                             |
| ρ_F      | 只表示接触力安全裕度。其值越低说明越接近力边界。                                                                               |
| ξ        | 表示力—位增广状态。若第五章使用 ξ_I，应说明其为切向/法向分解后的综合状态。                                                     |

# 10 后续修改顺序建议

正式改稿时建议先处理结构，再处理局部句子。若先在旧章节上逐句润色，容易保留原来的刚性约束和工业双仲裁框架，后续还要反复返工。较稳妥的顺序如下。

    ustcsetup.tex、摘要、目录标题和第六章总结，使题名和章节对象先统一。

以上修改完成后，全文应呈现为一条连续链路：柔性接触任务提出力—位协调问题，第三章给出执行层合作博弈控制器，第四章给出人机输入进入参考层的动态仲裁，第五章用统一平台验证二者组合效果。这样的结构能够回应导师关于总体定位、章节关系、第三章贡献、第四章对比和第五章实物实验的主要意见。

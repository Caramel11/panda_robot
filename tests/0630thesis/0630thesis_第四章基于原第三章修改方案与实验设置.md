## 1. 本章定位

当前版本论文第四章应定位为参考层方法章，题名建议采用：

```text
第 4 章 面向人机协同柔性操作的动态仲裁方法
```

第三章已经负责建立执行层合作博弈力位协同控制器，回答柔性接触任务中位置跟踪与接触力调节如何形成可解释折中。第四章接着回答另一个问题：在人类参与柔性接触操作时，操作者输入如何进入期望轨迹，哪些输入应被接受，哪些输入应被削弱，动态人机权重如何平滑变化。换言之，第三章处理“给定参考轨迹后如何执行”，第四章处理“人类监督输入如何生成安全参考轨迹”。

原论文第三章以刚性几何约束操作、人机共享控制、目标切换和远心运动实验为主。其可保留价值集中在四个方面：主端输入到监督参考的转化，基于交互强度、持续时间和空间风险的人机权重估计，绝对通道与增量通道结合的模糊仲裁，滤波限幅保证权重平滑变化。这些内容适合迁移为新第四章的人机动态仲裁模块。原第三章中较重的任务空间动力学推导、合作微分博弈控制律求解和刚性几何约束叙事，应从新第四章主线中压缩或迁出，以免和新第三章的执行层合作博弈控制器重复。

新第四章的贡献边界应写得稳健。模糊逻辑宜定位为工程实现工具，本章贡献在于面向柔性接触人机协同任务，把人类输入特征、切向和法向分解、接触力安全裕度、安全参考投影和权重平滑统一为参考层动态仲裁机制。其目标是保留安全切向修正，削弱危险法向压入，并为第三章执行层控制器提供平滑、有界、可解释的期望轨迹。

### 4.1 柔性接触任务中的人类介入

本节应从第三章留下的问题自然引出。第三章默认期望轨迹、期望接触力和安全边界已经给定，执行层控制器负责力位协同。实际人机协同柔性操作中，参考轨迹经常需要操作者在线修正。操作者可能根据视觉观察、工件缺陷、接触声响、材料变形或任务经验给出横向绕行、局部补扫、目标重定向或停止推进等监督输入。此类输入具有价值，但也可能包含手部抖动、短时误触和危险法向压入。

本节建议设置“问题 4.1 柔性接触人机动态仲裁问题”。问题定义中应包含：

- 机器人自主参考 `x_r(t)`；
- 主端输入 `s_h(t)=\{\Delta x_m(t),\dot x_m(t),f_h(t)\}`；
- 直接遥操作参考 `x_{\mathrm{tele}}(t)`；
- 人侧候选参考 `x_h(t)`；
- 人侧安全参考 `x_h^{\mathrm{safe}}(t)`；
- 最终期望轨迹 `x_d(t)`；
- 人机仲裁参数 `\alpha_{\mathrm{HR}}(t)`；
- 接触力安全区间 `[F_{\min},F_{\max}]`；
- 可选几何约束误差 `e_{\mathrm{gc}}(t)`。

问题目标应写成：设计参考生成、输入分解、安全投影和动态仲裁律，使安全切向修正能够平滑影响最终期望轨迹，危险法向压入受到抑制，短时扰动不会引起权重突跳，并使第三章执行层控制器接收到有界、连续或分段连续的参考信号。

本节还应明确 `\beta` 与 `\alpha_{\mathrm{HR}}` 的区别。`\beta` 是直接遥操作参考与机器人自主参考之间的候选参考融合系数，主要用于形成候选人侧参考；`\alpha_{\mathrm{HR}}` 是安全人侧参考进入最终期望轨迹的权重，直接决定人类监督对任务参考的影响程度。两者应保持清晰边界。

### 4.2 人侧监督参考生成

本节可保留原第三章中监督参考生成的基本思想，但需要把刚性几何约束叙事改为柔性接触场景。建议先定义直接遥操作参考：

```tex
x_{\mathrm{tele}}(t)=x(t)+K_m\Delta x_m(t),
```

其中 `K_m` 为主从比例矩阵，`\Delta x_m(t)` 为主端位移增量。该公式的物理意义是把操作者手部位移转化为从端接触点附近的候选修正。公式后应说明，`x_{\mathrm{tele}}` 进入执行层前需要经过筛选，因为它可能包含抖动、延迟和法向过压风险。

随后定义人侧候选参考：

```tex
x_h(t)=\beta(t)x_{\mathrm{tele}}(t)+\bigl(1-\beta(t)\bigr)x_r(t).
```

这里的 `\beta(t)` 可以由输入强度、持续时间和方向一致性初步生成，也可以沿用原第三章的 S 型映射：

```tex
\beta_r(t)=\frac{1}{1+\exp[-\gamma_\beta(d_{\mathrm{dev}}(t)-d_{\mathrm{th}})]},
\quad
\dot\beta(t)=\lambda_\beta(\beta_r(t)-\beta(t)).
```

建议在正文中解释 `d_{\mathrm{dev}}=\|x_{\mathrm{tele}}-x_r\|` 的含义。它表示人类直接参考与机器人自主参考之间的偏离程度，偏离越大，说明操作者修正意图越明显。但仅有偏离距离还不足以判断安全性，因此需要后续安全投影。

本节还可引入人类输入方向一致性：

```tex
C_h(t)=
\frac{v_h^{\mathrm T}(t)v_r(t)}
{\|v_h(t)\|\|v_r(t)\|+\varepsilon_c}.
```

其中 `v_h` 为人类输入对应的期望运动方向，`v_r` 为机器人自主参考速度。`C_h>0` 表示人类输入大体沿自主路径方向，`C_h<0` 表示反向或明显偏离，`C_h\approx0` 多对应横向局部修正。柔性表面扫描中，横向修正常常有价值，因为操作者可能希望绕开缺陷区域或扩大覆盖区域；法向修正需要额外审查，因为它直接影响接触力。

### 4.3 接触安全参考投影

本节是新第四章相较原第三章的关键增强。原第三章主要根据交互强度、持续时间和空间风险调节人机权重，在柔性接触场景中还必须判断人侧参考是否可能导致接触力越界。建议吸收当前第五章中安全投影的成熟写法。

先定义局部接触力预测模型：

```tex
\hat F(\bar x;t)=y_f(t)+\hat K_e(t)n_c^{\mathrm T}(t)(\bar x-x(t)).
```

其中 `n_c(t)` 为接触法向，`\hat K_e(t)` 为当前表观刚度估计，`\bar x` 为候选参考点。该模型用于参考层筛选，完整柔性接触建模仍由第三章执行层模型承担。正文应说明：若候选参考沿压入方向移动，预测接触力增加；若沿卸载方向移动，预测接触力降低。在小步长和高频控制条件下，该近似足以用于安全参考判断。

定义安全参考集合：

```tex
\mathcal X_s(t)=
\left\{\bar x\in\mathcal X_{\mathrm{ws}}\middle|
F_{\min}+\Delta_F\le \hat F(\bar x;t)\le F_{\max}-\Delta_F,\
e_{\mathrm{gc}}(\bar x)\le e_{\mathrm{gc}}^{\max}
\right\}.
```

如果无远心运动约束或固定通道约束，可省略 `e_{\mathrm{gc}}` 项。`\Delta_F` 是安全余量，用于预留传感器噪声、刚度估计误差和离散控制延迟。随后定义人侧安全参考：

```tex
x_h^{\mathrm{safe}}(t)=
\arg\min_{\bar x\in\mathcal X_s(t)}
\|\bar x-x_h(t)\|^2.
```

该投影选择离操作者意图最近的安全参考。若 `x_h` 位于安全集合内，投影基本不改变输入；若 `x_h` 沿法向继续压入并可能导致接触力越界，投影会主要削弱法向分量，同时尽量保留切向分量。

为了更清晰地表达切向和法向作用，定义：

```tex
P_N(t)=n_c(t)n_c^{\mathrm T}(t),\quad
P_T(t)=I-P_N(t).
```

最终期望轨迹可写为：

```tex
x_d(t)=x_r(t)
+\alpha_{\mathrm{HR}}(t)P_T(t)\bigl(x_h^{\mathrm{safe}}(t)-x_r(t)\bigr)
+\alpha_{\mathrm{HR}}(t)\kappa_N(t)P_N(t)\bigl(x_h^{\mathrm{safe}}(t)-x_r(t)\bigr).
```

其中 `\kappa_N(t)\in[0,1]` 为法向人类输入抑制系数，可由接触力安全裕度生成，例如 `\kappa_N=\rho_F` 或 `\kappa_N=\operatorname{sat}(\rho_F,\kappa_{\min},1)`。该式应在正文中重点解释：切向修正影响扫描覆盖，法向修正影响接触力；当接触力接近边界时，系统保留切向监督能力，同时削弱法向压入对参考轨迹的影响。

### 4.4 多因素动态仲裁设计

本节保留原第三章的绝对通道、增量通道和滤波结构，但输入变量应改写为柔性接触人机协同任务中的可观测特征。建议采用以下四类输入：

| 特征 | 建议符号 | 物理含义 |
| --- | --- | --- |
| 人类干预强度 | `I_h` | 主端力、速度或位移幅值归一化，表示操作者当前修正意图强弱。 |
| 干预持续时间 | `T_h` | 有效输入持续时间归一化，用于区分短时误触和持续意图。 |
| 方向一致性 | `C_h` | 人类输入方向与自主参考方向的夹角关系，用于识别顺向、反向和横向修正。 |
| 接触安全状态 | `\rho_F` 或 `R_s` | 接触力距离安全边界的裕度，也可包含几何约束裕度或任务阶段。 |

绝对仲裁通道给出当前时刻人侧参考应占的基础权重：

```tex
\lambda_{\mathrm{abs}}(t)=
\mathcal F_{\mathrm{abs}}\bigl(I_h(t),T_h(t),C_h(t),\rho_F(t)\bigr).
```

增量仲裁通道给出权重变化趋势：

```tex
\Delta\lambda_{\mathrm{inc}}(t)=
\mathcal F_{\mathrm{inc}}\bigl(\dot I_h(t),\dot T_h(t),\dot C_h(t),\dot\rho_F(t)\bigr).
```

原第三章中的 `fis_abs_surface`、`fuzzy_rules_table`、`fis_inc_surface` 和 `delta_fuzzy_rules_table` 可继续使用，但正文应把它们解释为多因素仲裁的可视化，模糊控制器本身宜定位为工程实现工具。图前文字应说明绝对通道用于判断当前人侧权重水平，增量通道用于判断权重变化方向；图后再分析规则曲面如何抑制短时扰动并响应持续修正。

滤波平滑可沿用原第三章的状态估计结构。若保留卡尔曼滤波，可写为：

```tex
\chi_k=[\lambda_k,\dot\lambda_k]^{\mathrm T},
\quad
\chi_{k|k-1}=A_f\chi_{k-1|k-1}+B_f\Delta\lambda_{\mathrm{inc},k},
```

```tex
y_k=C_f\chi_k+v_k.
```

最终人机仲裁参数采用限幅和一阶滤波：

```tex
\alpha_{\mathrm{HR},r}(t)=
\operatorname{sat}(\hat\lambda(t),\alpha_{\min},\alpha_{\max}),
```

```tex
\dot\alpha_{\mathrm{HR}}(t)=
\lambda_{\mathrm{HR}}\bigl(\alpha_{\mathrm{HR},r}(t)-\alpha_{\mathrm{HR}}(t)\bigr).
```

正文应解释 `\lambda_{\mathrm{HR}}` 的工程意义。取值较大时响应更快，但容易跟随手部抖动；取值较小时参考更平滑，但操作者可能感觉系统响应迟缓。因此它是人机交互响应速度与闭环平滑性之间的设计参数。

### 4.5 有界性与可执行性分析

第四章理论分析宜简洁，服务于“参考层仲裁不会给第三章执行层控制器提供不可控输入”这一结论。建议设置以下模块。

**假设 4.1 人类输入与自主参考有界。** 机器人自主参考、主端输入和人侧候选参考在实验工作区内有界，一阶导数分段连续。短时冲击可通过限幅和滤波处理。

**假设 4.2 安全集合非空与局部凸性。** 对每个控制周期，安全参考集合 `\mathcal X_s(t)` 非空、闭且局部凸。若实物中安全集合为空，系统进入硬安全监督或退回自主参考。

**引理 4.1 安全参考投影的存在性与有界性。** 在安全集合非空、闭且局部凸，人侧候选参考有界的条件下，投影问题存在解，且 `x_h^{\mathrm{safe}}(t)` 有界。若集合和参考随时间连续变化，则投影结果分段连续。

**引理 4.2 人机仲裁参数的区间不变性与变化率上界。** 若 `\alpha_{\mathrm{HR}}(0)\in[\alpha_{\min},\alpha_{\max}]`，且目标权重经限幅后也在该区间内，则一阶滤波生成的 `\alpha_{\mathrm{HR}}(t)` 始终位于该区间，并满足 `|\dot\alpha_{\mathrm{HR}}|\le\lambda_{\mathrm{HR}}(\alpha_{\max}-\alpha_{\min})`。

**引理 4.3 最终期望轨迹的有界性。** 由有界的 `x_r`、有界的 `x_h^{\mathrm{safe}}`、有界的 `\alpha_{\mathrm{HR}}` 和 `\kappa_N` 可得最终期望轨迹 `x_d` 有界；在分段连续条件下，`x_d` 分段连续。

**定理 4.1 有界参考下的闭环实际有界性。** 固定采用第三章执行层控制器。若第三章闭环系统对有界参考和有界扰动具有实际有界性，且第四章生成的 `x_d` 及其导数有界，则整体闭环状态保持有界，并进入与参考变化率、接触模型残差和投影误差相关的有界邻域。

定理后应设置“注”说明工程边界。安全参考投影和动态仲裁提供连续安全筛选，不等价于严格控制屏障函数；实物实验仍需硬安全阈值、速度限幅、力上界停止和急停策略。这样表述更符合控制论文规范，也避免过度承诺。

### 4.6 仿真与实物实验验证

第四章实验应固定第三章执行层控制器，只替换参考层仲裁策略。这样实验差异集中在人类输入如何进入期望轨迹，避免控制器和仲裁器同时变化导致结论不清。

建议 4.6 节结构如下：

```text
4.6 仿真与实物实验验证
4.6.1 实验平台与人类输入序列
4.6.2 对比仲裁策略与评价指标
4.6.3 安全切向修正实验结果
4.6.4 不安全法向压入实验结果
4.6.5 短时扰动与持续干预实验结果
4.6.6 长工具约束补充实验
```

如果第五章已经承担长工具和远心运动综合验证，4.6.6 可删除或压缩为补充讨论。

## 4. 仿真实验设置

第四章仿真实验用于完整比较不同参考层仲裁策略，并为实物实验选择参数。仿真应使用第三章已经验证的力位协同控制器作为固定执行层。

### 4.1 柔性表面扫描中的人类输入仿真

任务设置为机器人沿柔性表面扫描，法向保持期望接触力。人类输入由预设脚本生成，保证不同方法面对完全相同的输入序列。

| 项目 | 建议设置 |
| --- | --- |
| 扫描路径 | 沿 `x` 方向 8 cm 至 12 cm，速度 2 mm/s 至 5 mm/s。 |
| 柔性环境 | 低刚度区和高刚度区拼接，可加入局部缺陷区域。 |
| 期望接触力 | `F_d=0.5 N` 至 `0.8 N`。 |
| 力安全区间 | 例如 `[0.35,1.20] N`，按实物材料修正。 |
| 控制频率 | 执行层和仲裁层均建议 100 Hz。 |
| 重复次数 | 每种方法每类输入至少 10 次仿真重复。 |

人类输入建议分为四类。

| 输入类型 | 设置方式 | 验证目的 |
| --- | --- | --- |
| 安全切向修正 | 在 5 s 至 10 s 内施加 10 mm 至 20 mm 横向偏移。 | 检验安全修正能否进入最终轨迹。 |
| 不安全法向压入 | 在 5 s 至 8 s 窗口内给出 3 mm 至 8 mm 法向压入。 | 检验安全投影和法向抑制能否降低力峰值。 |
| 短时扰动 | 给出 0.2 s 至 0.5 s 的小幅脉冲或反向输入。 | 检验权重滤波是否抑制误触和抖动。 |
| 持续重定向 | 给出 3 s 至 5 s 的方向一致修正。 | 检验人机权重是否平滑上升并改变参考轨迹。 |

对比仲裁策略建议包括：

| 方法代号 | 策略 | 验证目的 |
| --- | --- | --- |
| 无人输入 | `x_d=x_r` | 提供执行层控制器基线，显示无监督修正时的轨迹覆盖。 |
| 直接接受 | `x_d=x_{\mathrm{tele}}` 或直接叠加主端输入 | 展示危险法向输入会推高接触力。 |
| 固定比例 | 固定 `\alpha_{\mathrm{HR}}` 融合人侧参考和自主参考 | 展示固定权重难以区分不同输入类型。 |
| 单因素 S 型 | 仅由输入幅值或参考偏差生成权重 | 展示单一变量对切向和法向风险区分不足。 |
| 多因素无投影 | 使用多因素动态权重，但不进行安全参考投影 | 分离动态权重和安全投影的作用。 |
| 本章方法 | 多因素动态仲裁、切向和法向分解、安全参考投影、权重滤波 | 验证完整参考层仲裁机制。 |

### 4.2 参数敏感性仿真

第四章参数敏感性不宜展开过大网格。建议只测试三类参数：

| 参数 | 取值建议 | 观察指标 |
| --- | --- | --- |
| 人机权重滤波系数 `\lambda_{\mathrm{HR}}` | 低、中、高三档 | 权重响应时间、短时扰动峰值、轨迹突变量。 |
| 安全余量 `\Delta_F` | 小、中、大三档 | 危险法向输入抑制率、切向修正接受率、任务轨迹误差。 |
| 法向抑制下限 `\kappa_{\min}` | 0、0.2、0.4 | 法向压入削弱量、接触力峰值、操作者修正保留程度。 |

该仿真用于解释参数物理意义，不用于寻找全局最优参数。结果可用热图或折线图展示，正文中说明参数变化符合预期即可。

### 4.3 长工具约束补充仿真

为了与第五章有远心运动约束工况衔接，可设置长工具补充仿真。任务为长工具通过简化套管接触柔性材料，操作者给出切向修正和法向误推。执行层控制器仍固定为第三章方法。

| 项目 | 建议设置 |
| --- | --- |
| 扫描长度 | 3 cm 至 5 cm。 |
| 期望接触力 | `F_d=0.3 N` 至 `0.6 N`。 |
| 输入类型 | 安全切向修正、不安全法向压入、短时扰动。 |
| 对比方法 | 固定比例、单因素 S 型、本章方法。 |
| 额外指标 | 远心运动误差均方根值和峰值。 |

该仿真只作为补充，结论应服务于第五章综合实验。第四章主结论仍来自无远心运动约束柔性接触场景中的人类输入筛选。

## 5. 实物实验设置

第四章实物实验应尽量复用第三章无远心运动柔性表面扫描平台。操作者输入可以先用脚本化主端输入保证重复性，再补充少量真实操作者实验。每种主要方法每个工况建议重复 5 次。

### 5.1 无远心运动约束柔性表面扫描实物实验

该实验是第四章实物验证的优先项。平台使用 Franka 机械臂、短圆头探针或短接触杆、柔性材料和主端设备。第三章执行层控制器保持固定，只切换参考层仲裁策略。

| 项目 | 建议设置 |
| --- | --- |
| 机器人平台 | Franka 机械臂。 |
| 主端设备 | Novint Falcon 或当前可用主端设备，也可用脚本化输入替代人类重复动作。 |
| 柔性材料 | 硅胶、泡棉、橡胶条或海绵硬底板组合。 |
| 任务 | 沿 `x` 方向扫描 8 cm 至 12 cm，维持 `0.5 N` 至 `0.8 N` 接触力。 |
| 输入 | 横向绕行、法向压入、短时脉冲、持续修正。 |
| 方法 | 直接接受、固定比例、单因素 S 型、多因素无投影、本章方法。 |
| 重复次数 | 每种方法每类输入至少 5 次。 |

实物实验应记录时间戳、末端位置、期望轨迹、主端输入、接触力、`\alpha_{\mathrm{HR}}`、`\beta`、`\rho_F`、`\kappa_N`、安全投影前后参考、第三章执行层控制输入和计算时间。若传感器存在明显零漂，每次实验前静止 3 s 至 5 s 做零偏估计。

### 5.2 安全切向修正实验

任务为操作者在扫描过程中给出横向偏移，使机器人绕开局部标记区域或覆盖新的感兴趣区域。该实验主要验证本章方法能否保留有价值的人类经验。

预期现象：直接接受方法和本章方法都能较好跟随切向修正，但直接接受方法在真实手部输入中可能引入额外法向扰动；固定比例方法接受程度受固定权重限制；单因素 S 型方法对持续修正有响应，但对接触力风险缺少显式判断；本章方法应在较高切向修正接受率下保持低力峰值和低越界时间。

### 5.3 不安全法向压入实验

任务为操作者在稳定扫描中沿法向给出继续压入命令。该实验应设置硬安全上限，超过硬阈值立即卸载或停止推进。

预期现象：直接接受方法会把法向输入写入期望参考，导致接触力峰值增大；固定比例方法会削弱一部分输入，但在高权重设置下仍可能越界；多因素无投影方法可以降低权重，但当持续输入较强时仍可能保留危险参考；本章方法通过安全投影和法向抑制系数削弱压入分量，使危险法向输入抑制率更高，并减少力越界时间。

### 5.4 短时扰动与持续干预实验

短时扰动实验给出 0.2 s 至 0.5 s 的脉冲输入或反向输入，用于验证权重不会因误触突跳。持续干预实验给出 3 s 至 5 s 的方向一致输入，用于验证系统能够接受明确的人类意图。

预期现象：本章方法的 `\alpha_{\mathrm{HR}}` 对短时扰动响应较小，恢复时间较短；对持续输入则平滑上升，使最终参考逐步偏向安全人侧参考。若使用真实操作者实验，应把结果定位为平台可行性验证，避免写成正式多被试用户研究。

### 5.5 长工具约束补充实物实验

若已有长工具和简化套管平台，可保留原第三章部分实物数据作为补充。该实验主要验证参考层仲裁在有远心运动边界时仍能执行。方法对比可压缩为固定比例、单因素 S 型和本章方法，指标增加远心运动误差均方根值和峰值。

该实验的结果应放在第四章末尾或第五章综合实验中。若第四章篇幅紧张，建议将其迁入第五章，以保持第四章主线集中在人类输入筛选和接触安全参考生成。

## 6. 评价指标与物理含义

第四章指标应围绕人类输入处理效果组织，力误差和轨迹误差作为辅助指标。建议统一使用下列指标。

| 指标 | 数学定义或计算方式 | 物理意义 |
| --- | --- | --- |
| 切向修正接受率 | `R_{\mathrm{acc}}=\frac{\sum_k\|P_T(x_{d,k}-x_{r,k})\|}{\sum_k\|P_T(x_{h,k}-x_{r,k})\|+\varepsilon}` | 衡量安全切向人类修正进入最终参考的比例。 |
| 危险法向输入抑制率 | `R_{\mathrm{sup}}=1-\frac{\sum_{k\in\mathcal K_N}\|P_N(x_{d,k}-x_{r,k})\|}{\sum_{k\in\mathcal K_N}\|P_N(x_{h,k}-x_{r,k})\|+\varepsilon}` | 衡量可能导致过压的法向输入被削弱的程度。 |
| 力越界时间 | `T_{\mathrm{vio}}=T_s\sum_k \mathbb I(y_{f,k}<F_{\min}\ \mathrm{or}\ y_{f,k}>F_{\max})` | 衡量人类输入是否导致接触力离开安全区间。 |
| 力峰值 | `F_{\mathrm{peak}}=\max_k y_{f,k}` 或 `\max_k |y_{f,k}-F_d|` | 衡量危险法向压入产生的瞬时风险。 |
| 切向轨迹误差 | `E_T^{\mathrm{RMS}}=\sqrt{\frac{1}{N}\sum_k\|P_T(x_k-x_{d,k})\|^2}` | 衡量执行层是否跟随最终参考中的切向修正。 |
| 权重平滑性 | `S_\alpha=\operatorname{std}(\alpha_{\mathrm{HR},k}-\alpha_{\mathrm{HR},k-1})` | 衡量人机权重变化是否平滑，避免抖动。 |
| 响应时间 | `t_{\mathrm{rise}}` 或达到目标权重 90% 的时间 | 衡量系统对持续明确输入的响应速度。 |
| 投影修正量 | `\|x_h^{\mathrm{safe}}-x_h\|` 及其切向、法向分量 | 说明安全投影主要削弱的是法向危险输入还是整体压制输入。 |
| 远心运动误差 | `E_{\mathrm{gc}}^{\mathrm{RMS}}` 和 `E_{\mathrm{gc}}^{\max}` | 仅用于长工具补充工况，衡量通道几何合规性。 |

分析顺序建议为：先看 `R_{\mathrm{acc}}` 和 `R_{\mathrm{sup}}`，再看力越界和力峰值，最后看权重平滑性、响应时间和轨迹误差。这样可以突出第四章的核心问题，即如何区分安全输入和危险输入。

## 10. 本章预期结论边界

第四章最终结论建议写成：在所设置的人机协同柔性接触操作中，多因素动态仲裁能够区分安全切向修正、危险法向压入、短时扰动和持续干预。通过安全参考投影和切向法向分解，系统能够在较高切向修正接受率下减少危险法向输入造成的力峰值和越界时间；通过双通道权重估计和滤波，系统能够抑制短时扰动引起的权重突跳，并对持续明确输入平滑响应。

结论应避免写成“提出全新仲裁理论”或“严格保证所有输入安全”。更合适的边界是：本章在第三章执行层控制器基础上，提供了面向柔性接触任务的人类输入筛选和参考生成机制。其安全性依赖局部力预测、参考投影、权重滤波和硬安全监督共同作用；在更复杂曲面、更多操作者和长期交互任务中仍需进一步验证。

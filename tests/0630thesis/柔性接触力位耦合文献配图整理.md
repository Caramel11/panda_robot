# 柔性接触中的力–位耦合示意图：近五年高水平文献配图整理

> 筛选标准：2021–2026 近五年；优先考虑 IEEE T-RO、RSS、ICRA、IROS、Science Robotics、IEEE RA-L 等高水平期刊/会议；图中能够体现力–位耦合、接触顺应、柔性变形、接触斑、软组织/柔性物体接触等关系。
> 使用建议：不建议直接截图论文原图，建议根据其物理关系重绘，并在图注中写明 *Adapted from ...*。

## 2. 最建议论文中重绘的组合

### 2.1 主图：软表面力控操作闭环

参考 **Wijayarathne et al., IEEE T-RO 2023** 的软表面力控操作任务。

建议画成：

- 机器人末端位移 / 速度；
- 软接触压入深度；
- 法向力 / 切向力；
- 软体变形；
- 控制器根据力反馈修正轨迹。

可用于表达：

> 机器人末端运动并非只决定几何位姿，还会通过接触引起柔性环境变形；柔性环境的变形反过来改变接触力，从而形成力–位耦合闭环。

### 2.2 接触细节图：接触斑与柔性变形

参考 **Van der Merwe et al., RSS 2023** 的 contact patch 与 deformable object estimation 图。

建议在局部放大图中标注：

- 接触斑面积：\(A_c\)
- 法向接触力：\(F_n\)
- 切向接触力：\(F_t\)
- 压入深度：\(\delta\)
- 柔性体位移场：\(u(x)\)
- 局部等效刚度：\(K(x)\)

可用于表达：

> 接触位置与接触面积不是固定量，而会随末端位移、材料刚度和柔性体变形而变化；因此力的大小、方向和分布与位姿状态深度耦合。

### 2.3 应用图：医疗软组织或工业柔性物体

根据论文场景选择：

- 如果偏 **医疗 / 软组织 / RCM 约束**：优先参考 **Jiang et al., IEEE RA-L 2021** 和 **Bao et al., IEEE RA-L 2021** 的机器人超声场景；
- 如果偏 **工业柔性物体 / DLO / 线缆装配**：优先参考 **Wilson et al., ICRA 2023** 的线缆装配和 **Wang et al., RA-L / IROS 2022** 的布料接触力估计。

## 3. 可重绘的力–位耦合结构图

```text
期望轨迹 x_d, v_d
        ↓
机器人末端位置 x, 姿态 R
        ↓
接触几何：压入深度 δ / 接触斑 A_c
        ↓
柔性体变形 u(x), 等效刚度 K(x)
        ↓
接触力 F_n, F_t / 力矩 τ
        ↓
力反馈 / 视觉触觉反馈
        ↓
阻抗、导纳、MPC 或 hybrid force-position controller 修正运动
```

## 4. 论文中可使用的示意图设计建议

### 4.1 总体构图

建议采用“三层结构”：

1. **机器人操作层**
   画机械臂末端或探头 / 夹爪 / 工具，标出期望位置 \(x_d\)、实际位置 \(x\)、速度 \(v\)。

2. **柔性接触层**
   画软组织、海绵、布料、线缆或柔性表面，标出压入深度 \(\delta\)、接触区域 \(A_c\)、变形位移场 \(u(x)\)。

3. **力反馈控制层**
   画力传感器、触觉传感器或视觉反馈，标出 \(F_n\)、\(F_t\)、\(\tau\)，并用箭头回到控制器。

### 4.2 推荐标注变量

| 变量 | 含义 | 图中建议位置 |
|---|---|---|
| \(x_d\) | 期望末端位置 | 控制器输出或轨迹箭头旁 |
| \(x\) | 实际末端位置 | 机器人末端旁 |
| \(\delta\) | 压入深度 / 接触变形量 | 末端与柔性体接触处 |
| \(A_c\) | 接触斑 / 接触面积 | 局部接触放大图 |
| \(u(x)\) | 柔性体位移场 | 柔性物体内部箭头 |
| \(K(x)\) | 局部等效刚度 | 柔性体材料区域 |
| \(F_n\) | 法向接触力 | 接触法线方向 |
| \(F_t\) | 切向摩擦 / 剪切力 | 接触切线方向 |
| \(\tau\) | 关节力矩或接触力矩 | 机器人关节或末端处 |

### 4.3 可写入图注的表述

> 柔性接触中的力–位耦合关系示意图。机器人末端位移 \(x\) 通过接触几何产生压入深度 \(\delta\)，进一步引起柔性体变形 \(u(x)\) 与接触斑 \(A_c\) 的变化；柔性体的等效刚度 \(K(x)\) 决定接触力 \(F_n, F_t\) 的大小和方向，而接触力又通过力反馈或阻抗/导纳控制修正末端轨迹，从而构成运动—变形—力反馈闭环。

必须新增或加强。导师明确指出第二章需要写阻抗控制。

需要包含：

1. 阻抗控制基本形式：

```text

```

2. 导纳控制与阻抗控制的差别。

```text
F_n=K_e\delta+B_e\dot\delta+\nu_f
F_{\min}<F_d<F_{\max}
```

重点说明：

- 柔性接触中位置误差会通过环境刚度转化为力误差；
- 力安全不是急停，而是需要在接近边界前提前调节控制行为。

```text
安全修正接受率
危险输入抑制率
力越界时间
轨迹误差
权重变化率
任务完成率
操作者输入响应延迟
```

导师指出当前第4章实物效果不明显，因此实验设计要主动触发仲裁差异，不能只做普通轨迹跟踪。

### 第5章：人机协同柔性物体操作系统集成与实物验证

目标：定位为系统集成与实物验证，不再作为新理论章。

当前问题：

- 当前第5章题为“面向工业约束接触任务的双仲裁合作博弈控制方法”，容易让人以为又提出一套新方法。
- 导师明确指出第5章不应强调“又提出一个框架”，而应把第3、4章整合起来做丰富实物实验。

建议结构：

```text
5.1 系统集成框架
5.2 实验平台与典型任务
5.3 消融实验与对比方法设计
5.4 RCM/固定通道条件下的实物验证
5.5 非 RCM 柔性接触条件下的实物验证
5.6 参数敏感性与鲁棒性分析
5.7 综合讨论
5.8 本章小结
```

#### 5.1 系统集成框架

写清楚：

- 底层：第3章合作博弈力--位控制器；
- 上层：第4章人类监督意图仲裁；
- 约束层：可选 RCM/导向孔/固定通道几何映射。

不要写“本章提出一种全新的双仲裁理论方法”。应写：

```text
本章将前两章方法集成到统一实验系统中，检验其在真实人机协同柔性物体操作任务中的闭环性能。
```

#### 5.2 实验平台与典型任务

至少规划两类任务：

1. RCM/固定通道柔性接触任务；
2. 非 RCM 柔性表面接触任务。

应用表述：

- 工业：柔性表面扫描、软质工件检测、打磨/抛光；
- 手术训练：长工具通过固定通道与柔性对象接触。

注意：这些是典型任务，不是论文总定位。

#### 5.3 消融实验设计

推荐分组：

```text
G0 固定阻抗 + 无仲裁
G1 合作博弈 + 无仲裁
G2 合作博弈 + 固定仲裁
G3 合作博弈 + 本文多因素仲裁
G4 完整系统
```

如果需要更强：

```text
G5 变阻抗 + 普通仲裁
G6 MPC 或 QP/CBF 安全滤波 + 普通仲裁
```

分析逻辑：

- G1 优于 G0：说明合作博弈控制器有效；
- G3 优于 G2：说明多因素仲裁有效；
- G4 综合最好：说明控制器与仲裁器耦合有价值。

#### 5.4 RCM/固定通道实物实验

优先完成。因为当前平台已有 RCM 相关基础。

指标：

```text
RCM RMS 误差
RCM 最大误差
力 RMS 误差
力峰值
力越界时间
末端轨迹误差
任务完成时间
人类修正接受率
危险输入抑制率
```

#### 5.5 非 RCM 柔性接触实物实验

建议任务简单但清晰：

```text
泡棉/硅胶/软橡胶表面恒力扫描
人给切向修正，系统应接受
人给法向压入，系统应抑制
环境局部刚度变化，系统应调节力--位优先级
```

如果实物数据不足，可先写成实验方案与初步结果，但正式论文中最好至少有一组非 RCM 实物结果。

#### 5.6 参数敏感性与鲁棒性

建议分析：

- 力安全上下界变化；
- \(\alpha_{\mathrm{FP}}\) 初值或滤波系数变化；
- \(\alpha_{\mathrm{HR}}\) 滤波系数变化；
- 环境刚度变化；
- 力噪声变化；
- 人类输入强度变化。

这部分可用仿真辅助实物，不必全部实物完成。

#### 5.7 综合讨论

必须客观：

- 不说“全面优于所有方法”；
- 说明合作博弈在综合平衡上有优势；
- 说明 CBF/QP 等安全方法可能在严格力约束上更保守；
- 说明本文优势在于可解释、实时、可分析、人类监督可接入。

### 第6章：总结与展望

按新主线总结：

1. 合作博弈力--位协同控制器；
2. 多因素人类监督仲裁；
3. 系统集成与实物验证。

展望：

- 更多柔性材料和真实工件；
- 更严格控制屏障函数安全约束；
- 多模态意图识别；
- 学习方法与合作博弈结合；
- 真实工业产线或手术器械验证。

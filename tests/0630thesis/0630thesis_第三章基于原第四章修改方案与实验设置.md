### 3.1 柔性接触任务描述与控制目标

本节用于替换原第四章章首的旧承接。第一段应从柔性接触操作的共性问题切入：工具沿切向完成扫描或接触操作，法向压入决定接触力；环境刚度变化会使相同位置偏差产生不同力响应。第二段引出控制困难：固定阻抗、纯位置控制或纯力控制都难以在变刚度环境中同时保证轨迹覆盖和力安全。第三段说明本章的研究边界：参考轨迹和期望接触力已给定，操作者输入如何生成参考轨迹由后续章节处理。

建议设置“问题 3.1 柔性接触力位协同控制问题”。问题定义中应包含：

- 任务空间位置 `x(t)` 和期望轨迹 `x_d(t)`；
- 环境接触力 `f_e(t)` 和受控标量接触力 `y_f(t)`；
- 期望力 `F_d` 与安全区间 `[F_min,F_max]`；
- 位置误差、速度误差、力误差和在线计算实时性要求；
- 若涉及远心运动约束，只写成补充工况，不列入本章基本问题定义。

需要明确，第三章的控制目标是在给定任务参考下求解执行层力位控制律。这样写可以自然引出第四章：真实人机协同任务中，参考轨迹还会受到操作者监督输入影响，因此需要单独研究动态仲裁。

### 3.2 柔性接触力位增广系统建模

本节保留原第四章中修正阻抗模型、开尔文沃伊特局部接触模型、环境刚度估计、力误差泄漏积分和增广误差系统推导。写作重点是减少重复推导，增加物理解释。

建议正文顺序如下。

第一，简要说明任务空间动力学已在第二章给出，本章在低层稳定伺服和局部线性化基础上采用修正阻抗动力学：

```tex
M\ddot x+C\dot x+K_v(x-x_d)=\mu+f_e .
```

公式后解释 `M`、`C` 和 `K_v` 分别对应期望惯性、阻尼和虚拟刚度，`μ` 为任务空间控制输入，`f_e` 为环境作用于工具的接触力。此处不要展开完整关节空间到任务空间推导，避免与第二章重复。

第二，建立局部柔性接触模型：

```tex
f_e=-K_e(x-x_s)-B_e(\dot x-\dot x_s)+\Delta_f(x,\dot x,t).
```

需要说明该模型只在局部短时间接触区间内有效，`K_e` 和 `B_e` 代表表观刚度和阻尼，`Δ_f` 表示材料非线性、摩擦、测量噪声和接触面变化引起的残差。这里可设置“假设 3.1 柔性接触模型局部有效性”。

第三，定义误差与增广状态：

```tex
e_p=x-x_d,\quad e_v=\dot x-\dot x_d,\quad e_f=f_e-f_d,
```

```tex
\dot\sigma_f=e_f-\lambda_f\sigma_f,\quad
\xi=[e_p^{\mathrm T},e_v^{\mathrm T},e_f^{\mathrm T},\sigma_f^{\mathrm T}]^{\mathrm T}.
```

正文中必须解释 `σ_f` 的物理意义。它表示带泄漏的力误差记忆，用于改善恒力跟踪中的稳态偏差，同时避免长期接触中的积分饱和。

第四，给出“引理 3.1 含残差项的增广力位误差系统”，结论为：

```tex
\dot\xi=A_c\xi+B_cu+d(\xi,t).
```

证明按照 `\dot e_p`、`\dot e_v`、`\dot e_f`、`\dot\sigma_f` 的顺序展开。逐轴模型可以保留，但不要使用大括号堆叠矩阵。若展示单轴矩阵，应使用公式和连等式，并在正文说明三维任务可由逐轴模型按块对角扩展。

第五，保留表观刚度估计：

```tex
K_{\mathrm{obs}}=\operatorname{sat}\left(\frac{|y_f|}{|\delta|},K_{\min},K_{\max}\right),
```

```tex
\hat K_{e,k}=\operatorname{sat}\left(\hat K_{e,k-1}+\alpha_K(K_{\mathrm{obs},k}-\hat K_{e,k-1}),K_{\min},K_{\max}\right).
```

正文应说明 `\hat K_e` 是面向增益调度的表观刚度估计，作用是识别软硬区域变化，使控制器能够选择更合适的力位优先级。该估计量只服务于控制调度，不承担精确材料辨识功能。

### 3.3 合作博弈力位协同控制器设计

本节是第三章理论主体。建议先写合作博弈的建模动机，再给出代价函数和反馈律推导。

第一段说明位置目标和力目标具有共同任务目标，但评价指标不同。位置目标关注扫描路径覆盖和末端运动平滑，力目标关注接触力接近期望值并避免过压或脱离。二者共享同一个控制输入，适合放在同一增广系统中统一求解。合作博弈的作用是通过帕累托有效解表达力位折中。

定义折扣型位置目标代价和力目标代价：

```tex
J_p(\xi_0,u)=\int_0^\infty e^{-\gamma t}\left(\xi^{\mathrm T}Q_p\xi+u^{\mathrm T}R_pu\right)\mathrm dt,
```

```tex
J_f(\xi_0,u)=\int_0^\infty e^{-\gamma t}\left(\xi^{\mathrm T}Q_f\xi+u^{\mathrm T}R_fu\right)\mathrm dt.
```

其中 `Q_p` 应主要惩罚位置误差和速度误差，`Q_f` 应主要惩罚力误差和力误差泄漏积分，`R_p` 与 `R_f` 对应控制输入代价。折扣因子 `γ` 的含义需要写清楚：它提高近期误差和近期力风险的权重，也使无限时域代价在局部模型近似和扰动存在时更便于分析。

定义力位优先级：

```tex
Q_\alpha=\alpha_{\mathrm{FP}}Q_p+(1-\alpha_{\mathrm{FP}})Q_f,
\quad
R_\alpha=\alpha_{\mathrm{FP}}R_p+(1-\alpha_{\mathrm{FP}})R_f.
```

全章统一 `\alpha_{\mathrm{FP}}` 的含义：数值越大，控制器越偏位置跟踪；数值越小，控制器越偏接触力调节。不要在实验分析中临时改变该含义。

建议保留“定理 3.1 固定力位优先级下的折扣帕累托反馈律”。给定固定 `\alpha_{\mathrm{FP}}`，若 `P_\alpha` 满足折扣代数黎卡提方程：

```tex
A_c^{\mathrm T}P_\alpha+P_\alpha A_c
-P_\alpha B_cR_\alpha^{-1}B_c^{\mathrm T}P_\alpha
+Q_\alpha-\gamma P_\alpha=0,
```

则最优反馈律为：

```tex
u_\alpha^*(\xi)=-R_\alpha^{-1}B_c^{\mathrm T}P_\alpha\xi .
```

证明可沿用原第四章写法，但应增加帕累托有效性的说明：在凸二次情形下，加权标量化问题的最优解对应支持帕累托边界上的一个工作点，调节 `\alpha_{\mathrm{FP}}` 等价于在位置性能与力性能之间移动工作点。

离线在线实现结构应保留：

```tex
K(\alpha_{\mathrm{FP}},\hat K_e)=R_\alpha^{-1}B_c^{\mathrm T}P_\alpha .
```

正文说明离线阶段在 `(\alpha_{\mathrm{FP}},\hat K_e)` 网格上求解黎卡提方程，在线阶段只进行查表或插值，从而避免在高频控制周期内求解完整优化问题。该点是与 MPC 或 QP 基线对比的重要优势。

### 3.4 力安全裕度与动态优先级调节

本节保留原第四章力安全裕度设计，但标题和正文均避免使用“人机仲裁”。建议使用“动态优先级调节”“力位优先级生成”“安全裕度驱动的调度”等表述。

首先定义接触力到安全边界的距离：

```tex
d_{\mathrm{lower}}=y_f-F_{\min},\quad d_{\mathrm{upper}}=F_{\max}-y_f.
```

再定义归一化力安全裕度：

```tex
\rho_F=\operatorname{sat}\left(
\frac{\min\{d_{\mathrm{lower}},d_{\mathrm{upper}}\}}{(F_{\max}-F_{\min})/2},0,1
\right).
```

正文需要解释：`\rho_F` 越接近 1，受控力越接近安全区间中部；越接近 0，说明接触力接近上界或下界，系统应提高对力风险的响应。还需要定义边界方向变量：

```tex
s_F=\operatorname{sat}\left(\frac{y_f-F_d}{(F_{\max}-F_{\min})/2},-1,1\right).
```

`s_F>0` 表示接触力偏大，`s_F<0` 表示接触力偏小。该符号必须在正文中给出物理意义。

动态优先级建议保留三类信息来源：力误差、安全裕度、估计刚度。模糊规则可作为工程实现，不要夸大为理论创新。更稳妥的表述是：模糊推理用于把归一化误差和安全裕度映射为连续目标优先级，再由刚度门控项修正稳态趋势，最后通过一阶滤波限制变化率。

一阶滤波方程可保留：

```tex
\dot\alpha_{\mathrm{FP}}=\lambda_\alpha(\alpha_r-\alpha_{\mathrm{FP}}).
```

建议设置“引理 3.2 力位优先级的区间不变性与变化率上界”。该引理证明 `\alpha_{\mathrm{FP}}` 保持在 `[α_min,α_max]` 内，并且变化率上界由 `λ_α(α_max-α_min)` 给出。该引理为后续慢变优先级下的性能分析服务。

### 3.5 最优性与有界性分析

本节应保留原第四章理论分析的主线，但删去过度一般化和与本章无关的内容。建议聚焦三个结论。

第一，固定优先级下的名义闭环稳定性。给定固定 `\alpha_{\mathrm{FP}}` 和稳定化黎卡提解，反馈矩阵 `A_c-B_cK_\alpha` 为赫尔维茨时，标称闭环系统渐近稳定。证明中可使用二次李雅普诺夫函数，但应承认折扣项会影响普通耗散不等式，因此最终稳定性由稳定化解和闭环矩阵赫尔维茨性保证。

第二，残差项影响下的实际有界性。真实系统包含 `d(\xi,t)`，因此不应写成全局渐近收敛。更严谨的结论是：在残差有界、参考信号有界和闭环稳定裕度满足条件时，状态进入与残差上界相关的有界邻域，真实代价相对标称代价的偏差可由残差界刻画。

第三，慢变优先级下的性能损失界。动态 `\alpha_{\mathrm{FP}}(t)` 提高了接触风险响应能力，但也引入时变反馈增益。理论上应说明性能损失与贝尔曼残差、增益表插值误差和 `|\dot\alpha_{\mathrm{FP}}|` 有关。这样可以解释为什么需要对优先级进行限幅和滤波。

本节后建议使用一段“注”说明理论条件的工程含义：接触模型只在局部有效，残差有界性依赖速度限幅、力阈值和工作空间限制；动态优先级的滤波常数不能只按响应速度取大，还应考虑闭环稳定裕度和传感器噪声。

### 4.1 变刚度柔性表面扫描仿真

该仿真是第三章主实验。任务为工具接触点沿切向扫描柔性表面，法向保持期望接触力。环境采用分段开尔文沃伊特模型，设置低刚度区、中等刚度区和高刚度区，刚度切换位置与扫描路径固定。

建议设置如下。

| 扫描路径 | 直线扫描 8 cm 至 12 cm，速度 2 mm/s 至 5 mm/s。 |

| 控制器 | 实现要点 | 在论文中的作用 |
| --- | --- | --- |
| 固定笛卡尔阻抗控制 | 采用固定 `K_z` 和 `D_z`，切向跟踪位置，法向由固定柔顺性产生力响应。 | 说明固定参数在变刚度环境下难以兼顾力峰值和轨迹误差。 |
| 力位混合控制 | 切向位置控制，法向力 PI 或 PID 控制，可加入导纳外环。 | 说明经典方向分解方法在刚度突变和模型误差下的局限。 |
| 固定优先级合作博弈 | `\alpha_{\mathrm{FP}}=0.2,0.5,0.8` 三档。 | 区分合作博弈反馈结构和动态优先级调节的贡献。 |
| MPC 或 QP 力位控制 | 基于同一增广模型，在短预测时域内优化位置误差、力误差和输入。 | 作为较强模型优化基线，比较实时性和模型依赖。 |
| 本章动态优先级合作博弈 | 使用力安全裕度、估计刚度和滤波后的 `\alpha_{\mathrm{FP}}` 查表反馈。 | 验证本文方法的综合折中能力。 |

预期现象应写得客观。固定高位置优先通常轨迹误差较小，但在硬区力峰值较大；固定强力优先在软区可能力误差较小，但在硬区可能出现振荡或轨迹漂移；力位混合控制对法向力误差有直接作用，但切向和法向耦合、接触法向估计和积分调参会影响稳定性；MPC 或 QP 可在仿真中取得较好综合指标，但在线计算量和模型误差敏感性需要单独说明；本文方法的目标是在力越界时间、力抖动、轨迹误差和计算时间之间保持稳定折中。

### 4.2 参数不确定性仿真

该仿真用于支撑理论中的残差有界性和参数误差讨论。建议选三类扰动，不要展开过大的参数网格。

| 扰动类型 | 设置方式 | 观察指标 |
| --- | --- | --- |
| 刚度估计偏差 | `\hat K_e=(1+\eta)K_e`，`\eta=-40%,-20%,0,20%,40%`。 | 力 RMS、越界时间、位置 RMS、`\alpha_{\mathrm{FP}}` 响应。 |
| 力测量噪声 | 在 `y_f` 中加入零均值高斯噪声或低频漂移。 | 力抖动、优先级变化率、控制输入峰值。 |
| 初始压入误差 | 改变初始接触深度或起始法向位置。 | 收敛时间、峰值力、是否触发硬安全阈值。 |

对比方法可只保留固定优先级、MPC 或 QP 和本文方法。若时间不足，参数不确定性仿真可不进入实物实验，只在第三章仿真讨论中说明方法对中等误差的鲁棒趋势。

### 4.3 长工具接触仿真

该仿真可作为补充工况，用于连接第五章远心运动实验。任务为长工具穿过固定点或简化套管后接触柔性材料，工具尖端进行短距离扫描。建议首次出现时写为“远心运动（remote center of motion, RCM）约束”，后文使用“远心运动约束”。

建议设置如下。

| 项目 | 建议设置 |
| --- | --- |
| 扫描长度 | 3 cm 至 5 cm。 |
| 期望接触力 | `F_d=0.3 N` 至 `0.6 N`。 |
| 力安全区间 | 依据长工具实物平台取较保守范围，如 `[0.25,0.80] N`。 |
| 对比方法 | 固定阻抗、固定优先级、本文动态优先级；MPC 或 QP 可只仿真。 |
| 额外指标 | 固定点到工具轴线距离的均方根误差和峰值误差。 |

该仿真的结论应谨慎表述。它定位为第三章的补充工况，用于说明执行层力位控制器在长工具几何边界下仍可工作，并为第五章综合实验铺垫。

## 5. 实物实验设置

实物实验应精简，优先保证可重复、可测量和结果可解释。第三章至少应补足无远心运动约束下的柔性表面扫描实物实验，用来回应导师关于“第三章不能只依赖远心运动或手术场景”的意见。

### 5.1 无远心运动约束柔性表面扫描实物实验

这是第三章最优先完成的实物实验。平台使用 Franka 机械臂末端短圆头探针或短接触杆，下方固定硅胶、泡棉、橡胶条或海绵硬底板组合。材料可拼接软区和硬区，也可在同一软垫下局部加入硬支撑形成等效刚度变化。

建议设置如下。

| 项目 | 建议设置 |
| --- | --- |
| 机械臂 | 当前 Franka 平台。 |
| 接触工具 | 短圆头探针，端部圆滑，避免划伤柔性材料。 |
| 柔性材料 | 两种硬度材料拼接，或同一材料下局部加硬底板。 |
| 扫描路径 | 沿 `x` 方向 8 cm 至 12 cm。 |
| 期望接触力 | `0.5 N` 至 `0.8 N`，正式值由材料预实验确定。 |
| 控制周期 | 建议 100 Hz 记录，若底层更高频，只保存下采样数据。 |
| 单次时长 | 20 s 至 40 s，接触建立阶段不计入统计。 |
| 重复次数 | 每种方法至少 5 次脚本化重复。 |

实物对比方法建议采用最小可靠组合：

```text
固定笛卡尔阻抗控制
力位混合控制
固定优先级合作博弈控制
动态优先级合作博弈控制
```

若调试时间不足，固定优先级可只保留 `\alpha_{\mathrm{FP}}=0.5`，用于消融动态优先级；若时间充足，可增加 `\alpha_{\mathrm{FP}}=0.2` 和 `0.8`。MPC 或 QP 可先作为仿真强基线，不强制进入实物实验。

实物实验前需要做四项标定：

| 标定项 | 操作 |
| --- | --- |
| 力零偏 | 每次实验开始前静止 3 s 至 5 s，记录力传感器零偏并扣除。 |
| 工具坐标 | 标定法兰到接触点的位移，保证接触点位置计算一致。 |
| 接触法向 | 平面材料可取世界 `z` 方向，倾斜材料需由初始接触姿态估计。 |
| 材料刚度 | 慢速压入几次，估计软区和硬区表观刚度范围，用于设置 `K_low` 和 `K_high`。 |

预期结果是：固定阻抗在硬区出现更明显力峰值；力位混合控制的法向力跟踪可能较好，但切向轨迹或法向抖动受 PI 参数影响；固定优先级在某一材料段可能表现较好，但跨软硬区域稳定性不足；动态优先级方法应降低力越界时间和力抖动，同时保持可接受的切向轨迹误差。

### 5.2 长工具接触补充实物实验

若已有长工具和简化套管平台，可设置补充实物实验；若时间不足，可将该实验放入第五章综合验证。第三章不宜让该工况压过无远心运动约束实验。

建议设置如下。

| 项目 | 建议设置 |
| --- | --- |
| 工具 | 长工具或腹腔镜类杆件，通过简化套管或虚拟固定点。 |
| 扫描路径 | 3 cm 至 5 cm 短路径。 |
| 期望力 | `0.3 N` 至 `0.6 N`。 |
| 重复次数 | 每种方法 5 次。 |
| 对比方法 | 固定阻抗、固定优先级合作博弈、动态优先级合作博弈。 |
| 额外指标 | 远心运动误差均方根值和峰值。 |

预期现象是：过低位置优先级会放大长工具姿态和固定点到轴线误差；过高位置优先级会在硬接触段产生更高力峰值；动态优先级应在力安全和几何边界之间取得较平衡结果。

## 6. 评价指标与物理含义

第三章实验指标必须先给数学定义，再解释物理意义。建议统一使用下列指标。

| 指标 | 数学定义 | 物理意义 |
| --- | --- | --- |
| 力均方根误差 | `E_F^{RMS}=\sqrt{\frac{1}{N}\sum_{k=1}^N(y_{f,k}-F_d)^2}` | 衡量接触力围绕期望力的平均偏差，反映恒力接触质量。 |
| 力峰值误差 | `E_F^{max}=\max_k |y_{f,k}-F_d|` | 衡量最危险瞬时偏差，反映柔性材料或工具受到冲击的风险。 |
| 力越界时间 | `T_{vio}=T_s\sum_{k=1}^N \mathbb I(y_{f,k}<F_{\min}\ \mathrm{or}\ y_{f,k}>F_{\max})` | 衡量接触力离开安全区间的累计时间，直接对应力安全性。 |
| 切向位置误差 | `E_T^{RMS}=\sqrt{\frac{1}{N}\sum_{k=1}^N\|P_T(x_k-x_{d,k})\|^2}` | 衡量扫描路径覆盖和切向轨迹跟踪质量。 |
| 法向位置误差 | `E_N^{RMS}=\sqrt{\frac{1}{N}\sum_{k=1}^N\|P_N(x_k-x_{d,k})\|^2}` | 衡量压入深度或法向位置变化，辅助解释力误差。 |
| 力抖动 | `J_F=\operatorname{std}(y_{f,k}-y_{f,k-1})` | 衡量接触力采样间变化剧烈程度，反映接触稳定性和平滑性。 |
| 控制输入强度 | `J_u=\frac{1}{N}\sum_{k=1}^N\|u_k\|^2` 或关节力矩均值 | 衡量控制代价和执行平稳性，避免用过大输入换取局部指标。 |
| 平均计算时间 | `T_{comp}^{avg}` 和 `T_{comp}^{max}` | 衡量控制器是否满足实时控制周期，尤其用于与 MPC 或 QP 对比。 |
| 优先级刚度相关系数 | `r_{\alpha K}=\operatorname{corr}(\alpha_{\mathrm{FP}},\hat K_e)` | 判断动态优先级是否随环境软硬变化产生可解释响应。 |
| 远心运动误差 | `E_{gc}^{RMS}` 和 `E_{gc}^{max}` | 仅用于长工具补充工况，衡量固定点到工具轴线距离。 |

指标分析顺序建议为：先分析力安全，再分析轨迹精度，然后分析优先级变化和实时性。这样读者会先看到柔性接触任务最关键的安全与接触稳定问题，再理解合作博弈优先级如何起作用。

## 8. 可保留的现有结果与需要补强的结果

原第四章已有的固定优先级和动态优先级仿真结果可以保留，但论文解释需要换角度。

无远心运动约束仿真中，已有结果显示动态优先级方法的力均方根误差约为 `0.1336 N`，接近固定均衡优先的 `0.1302 N`，力抖动为 `0.0017 N`，优于固定优先级。固定强力优先在高刚度段出现较大力峰值和抖动。这组结果适合用于说明固定优先级在跨刚度区域时存在失配，动态优先级能自动移动折中点。

长工具远心运动仿真中，已有结果显示动态优先级方法在力均方根误差、力抖动和远心运动峰值误差之间较均衡。该结果可作为补充工况，但不应在第三章中被解释为方法只服务于远心运动约束。

需要补强的结果主要有三类：

| 缺口 | 补强方式 |
| --- | --- |
| 缺少经典控制器对比 | 增加固定笛卡尔阻抗控制和力位混合控制仿真，实物至少保留这两类基线。 |
| 缺少无远心运动约束实物实验 | 补做短探针柔性表面扫描，固定人机输入，重点比较控制器。 |
| 缺少实时性对比 | 记录平均计算时间和最大计算时间，用于说明离线增益表相较 MPC 或 QP 的实时执行优势。 |

## 10. 本章预期结论边界

第三章结论应保持克制。建议最终写成：在所设置的变刚度柔性接触扫描任务中，合作博弈力位控制器能够用统一代价函数描述位置目标与力目标的折中；动态力位优先级可以根据力安全裕度和表观刚度调整反馈增益，使系统在力越界时间、力抖动、轨迹误差和实时性之间获得较稳定的综合表现。与固定阻抗和力位混合控制相比，本文方法的优势主要体现在多目标折中的可解释性和在线执行的连续性；与 MPC 或 QP 相比，本文方法通过离线增益表降低了在线求解负担。

若某个单项指标未达到最优，应如实说明。例如，固定均衡优先可能在某一刚度组合下取得略低的力均方根误差，MPC 或 QP 在仿真中可能取得更严格的边界控制。第三章重点证明合作博弈框架能够把力位耦合关系写成可解释、可求解、可实时执行的控制律，并在变刚度柔性接触中表现出更稳健的综合折中。

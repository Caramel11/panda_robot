# 0630thesis 全文框架与章节修改方案（深化版）

> 依据当前 GitHub LaTeX 版本、6 月 17 日导师沟通纪要、已确定的新题名与章节题名，以及童康硕士论文《非接触人机交互场景下基于微分博弈的协同控制策略研究》的章节组织方式整理。本文档用于指导后续正式改稿，不作为直接粘贴到论文正文的成稿。

## 0. 本轮修改的核心判断

当前论文最需要解决的不是局部文字润色，而是研究对象、章节递进和实验论证三件事的一致性。导师意见中反复出现的“手术还是工业”“第 3-5 章之间的关系”“第 5 章是否有技术贡献”“约束操作场景是否合适”等问题，指向同一个结构性问题：旧稿把手术、工业、RCM、柔性接触、共享控制、力位协调和双仲裁同时放入题名和章节说明中，使读者难以判断本文到底在研究哪一类控制问题。

后续应将全文统一到“人机协同柔性接触/柔性物体操作”这一研究对象上。手术训练、长工具 RCM 操作、工业表面扫描、软质工件检测、柔性材料打磨等都应作为典型边界条件或实验工况出现，而不再作为论文总定位。新的论文题名“基于合作博弈的人机协同柔性接触操作力-位协调控制研究”已经基本满足这一方向，其中“合作博弈”对应方法主线，“人机协同柔性接触操作”对应研究对象，“力-位协调控制”对应核心控制矛盾。

当前 LaTeX 主文件仍按 `chapter1` 至 `chapter6` 输入，适合保留六章结构；但 `ustcsetup.tex` 中题名、当前第三章题名以及第三至第五章的内容功能仍与新框架不一致。现有 `ustcsetup.tex` 中中文题名仍为“基于合作博弈的柔性接触操作人机协同与力–位协调控制方法研究”，英文题名仍偏向 constrained manipulation；`main_ustc.tex` 则说明论文已有“绪论—预备知识—三章主体—总结”的基本骨架，可在不破坏模板结构的前提下重排内容。当前第三章题名仍是“面向刚性约束操作场景的意图驱动合作微分博弈共享控制方法”，并在章首把 RCM 和固定通道约束作为主要对象，这与新的第三章“柔性接触力-位协同控制方法”不一致。

从导师沟通内容看，最稳妥的重构方式是：第三章承担合作博弈力-位协同控制器的主体理论和控制器对比；第四章承担面向人机协同柔性操作的动态仲裁和安全参考生成；第五章不再提出完整新方法，而是作为综合实验验证章，将第三章控制器和第四章仲裁器放在统一平台、统一工况、统一指标下验证。

## 1. 童康论文可借鉴的组织方式

童康硕士论文的目录结构对本文具有直接参考价值。该论文总体采用六章结构：第一章绪论，第二章预备知识，第三章解决一个前置估计问题，第四章提出协同控制策略，第五章进一步处理安全协同控制，第六章总结与展望。其章节顺序体现出“基础问题—主体方法—安全扩展—总结”的递进关系，而不是把若干应用场景平行堆叠。

在绪论部分，童康论文先介绍机器人技术和人机交互的工程背景，再说明非接触人机交互中的核心困难，随后把国内外研究现状分成微分博弈、人类行为预测和机器人安全性三个方向。每个方向都不是单纯罗列文献，而是围绕“现有方法能解决什么、仍有什么局限、本文为什么需要进入这个方向”展开。绪论末尾给出研究内容和组织架构，并配置研究思路结构框架图。本文第一章可以参考这种节奏，但要把三条研究现状改为“柔性接触与力控、人机协同与共享控制、合作博弈/多目标优化与安全约束”三条主线。

第二章方面，童康论文将预备知识写成后续章节使用的理论接口。例如，它先给出高斯过程、微分博弈和微分平坦的基本定义，再给出后续证明会直接调用的假设、定义和引理。其写法不是百科式扩展，而是先说明某一工具为什么出现在本文中，然后给出定义、公式和后文使用方式。本文第二章也应采用这种写法：机器人运动学、阻抗控制、柔性接触模型、合作博弈和 Lyapunov 稳定性分析都应服务于第三、四章，而不是泛泛综述控制理论。

在方法章节中，童康论文的典型节奏是：章首交代本章研究问题，随后进入“问题描述与定义”，再给出算法或控制器设计，接着进行理论分析，最后用仿真和实验验证。第三章通过问题、假设、算法、误差引理和仿真形成闭环；第四章通过问题转化、控制器设计、代价函数有界性、跟踪性能分析、仿真和实验形成闭环；第五章通过安全势能场、均衡策略存在性、安全性分析、仿真和实验形成闭环。本文第三、四章可以直接参考这一组织方式：每章都要有明确的问题定义、必要假设、核心定义、引理、定理和实验验证，不宜只写工程流程。

童康论文中“定义—假设—引理—定理—证明—注”的使用方式较规范。定义用于固定研究对象和概念边界，如高斯过程、纳什均衡、微分平坦空间；假设用于限定系统和函数条件，如有界性、Lipschitz 连续性、轨迹光滑性；引理用于证明中的中间环节，如误差界、代价函数有界性；定理用于给出本章主要性质，如跟踪收敛、概率误差界或安全性条件；注用于解释理论条件的保守性和工程含义。本文后续应避免把“假设”写成工程经验描述，也不要把普通变量解释都写成“定义”。

实验部分同样可参考童康论文。它先说明实验目的，再给出对象模型、参数、对比方法和评价指标；实物实验部分单独介绍平台、传感器、计算平台、场地和轨迹，随后给出定量结果。本文第五章尤其需要学习这种写法：实验平台和参数必须独立成节，指标必须先定义再展示，图表结果应回扣理论设计，而不是只说“效果更好”。

全文主线可在第一章用一张技术路线图表达：

```text
柔性接触操作需求
    ↓
位置轨迹精度、接触力安全、人类监督修正之间存在耦合
    ↓
第二章：建模与控制基础
    ↓

    ↓

```

该图的重点在于层级关系。第三章和第四章不是两个互不相干的算法，而是分别作用于执行层和参考层；第五章不是第三个新方法，而是统一实验平台上的组合验证。

## 3. 第一章详细修改方案

第一章建议保持“绪论”标题，内部结构调整为：1.1 研究背景及意义，1.2 国内外研究现状，1.3 本文研究内容与主要贡献，1.4 全文组织结构。若学校模板或习惯允许，可在 1.4 前加入“本文技术路线”小节，但不建议增加过多层级。

### 3.1 第 1.1 节：研究背景及意义

本节应采用从工程背景到控制问题的顺序。开头不要先问“手术还是工业”，而应先说明机器人正在进入柔性接触操作任务，接触式检测、打磨、扫描、软组织操作和长工具辅助操作都具有位置轨迹与接触力共同约束的特征。第一段可以描述工程需求，第二段描述力-位耦合，第三段描述人类监督介入的必要性，第四段引出合作博弈和动态仲裁。

建议段落功能如下。

| 段落 | 作用 | 写作重点 |
|---|---|---|
| 第 1 段 | 工程背景 | 柔性制造、机器人辅助手术训练、接触式检测等任务要求机器人与柔性环境稳定接触。 |
| 第 2 段 | 控制矛盾 | 位置误差影响覆盖质量，法向接触力影响安全和材料/组织损伤，二者通过环境刚度耦合。 |
| 第 3 段 | 人机协同需求 | 人可提供视觉判断、异常修正和工艺经验，但人的输入可能包含抖动和危险法向压入。 |
| 第 4 段 | 方法引出 | 需要在多目标、多约束和人在环条件下构造可解释、可实时和可验证的控制框架。 |

本节中“工业”和“手术”应作为例子而不是并列题目。推荐写法是：“该类任务在工业柔性检测和机器人辅助手术训练中具有不同表现形式，但在控制层面均可抽象为人类监督输入、机器人自主执行、柔性接触力安全和位置轨迹精度之间的协调问题。”

### 3.2 第 1.2 节：国内外研究现状

建议将旧的 1.2 改为四个方向。每个方向要采用“代表方法—适用范围—局限—本文切入点”的段落顺序，不能只罗列文献。

| 小节 | 建议题名 | 写作功能 |
|---|---|---|
| 1.2.1 | 柔性接触操作与力-位协调控制 | 综述阻抗控制、导纳控制、混合力/位控制、变阻抗和 MPC/QP，指出固定参数或单层优化难以解释动态力-位权衡。 |
| 1.2.2 | 人机协同与共享控制 | 综述共享自主、控制权分配、操作者意图识别、物理纠正等，指出柔性接触任务中还需要区分切向修正和法向危险输入。 |
| 1.2.3 | 合作博弈与多目标最优控制 | 综述微分博弈、LQR/ARE、帕累托加权、多目标反馈，说明本文用合作博弈处理位置目标和力目标的显式折中。 |
| 1.2.4 | 接触安全与约束执行 | 综述 CBF/QP、安全势函数、力边界约束、RCM/固定通道约束。该节篇幅不宜过大，避免重新把 RCM 写成全文主线。 |

导师提到 1.2.4 必要性问题，处理方式不是简单删除，而是检查它是否直接服务于贡献。如果旧 1.2.4 只是手术或工业应用综述，应并入 1.1 或相关研究中；若保留，则题名应指向“接触安全与约束执行”，用于支撑第五章有/无 RCM 的实验边界。

### 3.3 第 1.3 节：本文研究内容与主要贡献

该节建议按三项贡献写，顺序与第三、四、五章一致。

第一项写第三章：针对柔性接触操作中位置精度和接触力安全难以兼顾的问题，建立力-位增广误差系统，将位置目标和力目标构造为合作博弈中的两个目标，通过帕累托标量化和折扣黎卡提方程求解反馈律，并在变刚度接触中验证其折中能力。

第二项写第四章：针对人在环柔性操作中人类输入含义不唯一、有效修正和危险输入并存的问题，构造动态人机仲裁方法，结合交互强度、持续时间、方向一致性、力安全裕度和切向/法向分解，使安全切向修正进入期望轨迹，同时抑制可能造成力越界的法向输入。

第三项写第五章：搭建统一的仿真与实物实验体系，对第三章控制器和第四章仲裁器进行综合验证。实验覆盖无 RCM 的柔性表面接触和有 RCM 的长工具柔性操作，评价指标包括轨迹误差、力误差、力越界时间、几何约束误差、人类修正接受率、危险输入抑制率和实时性。

这三项贡献应避免“全面优于”“彻底解决”等绝对化表述。若缺少统计检验，使用“结果表明”“在所设工况下”“说明该方法具有较好的综合表现”。

### 3.4 第 1.4 节：全文组织结构

该节可以参考童康论文的写法，每章一段，长度控制在 6 段以内。重点是说明章节之间的承接关系，不要机械复述目录。

第一章介绍研究背景、现状和全文技术路线。第二章给出柔性接触建模和合作博弈控制所需基础。第三章建立执行层力-位协同控制器。第四章在第三章控制器基础上处理人类输入如何进入参考层。第五章将第三、四章放入统一实验平台验证。第六章总结全文并给出不足。

## 4. 第二章详细修改方案

第二章建议题名为“机器人柔性接触操作建模与控制基础”。若保留“预备知识”，也应在章首明确其服务对象：后续第三章的力-位增广建模、第四章的人机仲裁参考生成和第五章的实验指标定义。

### 4.1 推荐章节结构

```text
第 2 章 机器人柔性接触操作建模与控制基础
2.1 机器人任务空间运动学与动力学
2.2 柔性接触建模与阻抗控制
2.3 力-位协调控制与合作博弈基础
2.4 稳定性与扰动有界性分析工具
2.5 全文符号约定
2.6 本章小结
```

2.1 应保留正运动学、雅可比、关节空间动力学、任务空间动力学和任务空间误差定义。不要重复后续章节会再次推导的全部动力学，只需给出后续统一使用的符号与映射关系。

2.2 是导师明确要求补强的重点。该节应系统写阻抗控制和 Kelvin-Voigt 接触模型。阻抗控制部分说明其不是直接指定接触力，而是指定力与运动之间的动态关系；柔性接触部分说明接触力由压入深度、压入速度、刚度、阻尼和残差共同决定。该节应成为第三章力-位增广系统的直接来源。

2.3 写最优控制、合作博弈、帕累托有效和折扣型 LQR。这里不必证明所有定理，只需给出第三章会使用的加权标量化、代数黎卡提方程和反馈律形式。

2.4 可压缩。导师质疑 2.4 必要性，说明该节不应写成一般非线性稳定性教材。建议保留二次 Lyapunov、慢变参数和有界扰动三个工具，分别对应第三章固定权重稳定性、动态 α_FP/α_HR 变化率约束和接触模型误差。过长的鲁棒性分析放回方法章。

2.5 单独列符号表。该表应在全篇统一使用，避免第三章、第四章、第五章符号互相污染。

| 符号 | 含义 | 使用范围 |
|---|---|---|
| `x` | 任务空间接触点或工具尖端位置 | 全文 |
| `f_e` 或 `y_f` | 环境接触力或受控法向力 | 第 3-5 章 |
| `e_p,e_v,e_f,σ_f` | 位置、速度、力误差与力误差泄漏积分 | 第 3、5 章 |
| `ξ` | 力-位增广状态 | 第 3 章为主体，第 5 章可用 `ξ_I` 区分 |
| `α_FP` | 执行层位置目标与力目标优先级 | 第 3、5 章 |
| `ρ_F` | 接触力安全裕度 | 第 3-5 章 |
| `α_HR` | 参考层人机仲裁权重 | 第 4、5 章 |
| `β` | 直接遥操作参考与自主参考的内部融合系数 | 第 4 章 |
| `e_gc` | 固定点-轴线或 RCM 几何约束误差 | 第 5 章实验，必要时第 3 章附加工况 |

## 5. 第三章详细修改方案

新的第三章题名为“基于合作博弈的柔性接触力-位协同控制方法”。这一章应成为全文最核心的理论方法章。它的目标不是证明人机仲裁有效，也不是讨论 RCM 约束，而是回答柔性接触操作中为什么需要力-位协同，以及为什么合作博弈适合作为力-位协同控制器。

### 5.1 推荐章节结构

```text
第 3 章 基于合作博弈的柔性接触力-位协同控制方法
3.1 问题描述与控制目标
3.2 柔性接触力-位增广系统建模
3.3 合作博弈力-位协同控制器设计
3.4 力安全裕度与优先级调度
3.5 最优性与稳定性分析
3.6 仿真与实物实验验证
3.7 本章小结
```

### 5.2 章首两段写法

章首第一段应承接第一、二章，说明柔性接触任务中位置和力的耦合。推荐逻辑为：在表面扫描、柔性物体检测和软组织接触任务中，工具切向运动决定扫描覆盖，法向压入决定接触力；当环境刚度发生变化时，同样的位置误差会产生不同力响应，因此固定参数位置控制、固定阻抗控制或固定力控权重难以稳定处理全工况。

第二段引出合作博弈。可以写成：本章将位置跟踪目标和接触力调节目标视为作用于同一受控系统的两个目标。二者不是对抗关系，而是共同服务于柔性接触任务。合作博弈框架通过加权代价函数和帕累托解表达二者的折中，使控制器能够在不同力安全裕度和环境刚度下调整工作点。

### 5.3 本章应使用的定义、假设、引理和定理

建议采用以下模块，风格参考童康论文，但变量换成本文对象。

**定义 3.1 柔性接触力-位协调问题。** 定义任务空间位置 `x`、期望轨迹 `x_d`、受控接触力 `y_f`、期望力 `F_d`、安全区间 `[F_min,F_max]`，并说明控制目标是使位置误差和力误差有界，同时减少力越界时间。

**假设 3.1 任务空间动力学正则性。** 限定机器人在实验工作区内避开奇异位形，雅可比矩阵和等效任务空间模型有界，底层伺服可稳定执行任务空间命令。

**假设 3.2 柔性接触局部模型有效性。** 使用 Kelvin-Voigt 模型描述局部接触，环境刚度、阻尼和残差在紧集内有界。该假设为残差有界性分析服务，不应写成“环境完全线性”。

**定义 3.2 力-位增广状态。** 定义 `ξ=[e_p^T,e_v^T,e_f^T,σ_f^T]^T`，其中 `σ_f` 为泄漏积分状态。公式后需要解释每个状态的物理含义。

**引理 3.1 增广误差系统。** 由阻抗动力学和接触模型推导 `dot ξ=A_c ξ+B_c u+d(ξ,t)`。证明应按 `dot e_p`、`dot e_v`、`dot e_f`、`dot σ_f` 的顺序展开。

**定义 3.3 位置目标和力目标代价函数。** 定义 `J_p` 和 `J_f`，说明 `Q_p` 惩罚位置和速度误差，`Q_f` 惩罚力误差和积分状态。

**定义 3.4 力-位优先级。** 定义 `α_FP∈[α_min,α_max]`。务必全章统一：`α_FP` 越大，越偏位置跟踪；`α_FP` 越小，越偏力调节。若后续实验为了安全而采用相反趋势，必须改公式而不是在文字中变换含义。

**引理 3.2 加权矩阵正定性。** 证明 `Q_α⪰0`、`R_α≻0`。这是折扣 ARE 可解性的基础。

**定理 3.1 固定 `α_FP` 下的折扣帕累托反馈律。** 由折扣 HJB 或 LQR 推导 `u=-R_α^{-1}B_c^T P_α ξ`。证明围绕哈密顿函数对 `u` 求导展开，写法可参考童康论文中 HJB 到控制律的推导节奏。

**定理 3.2 残差扰动下的实际有界性。** 在 `d(ξ,t)` 有界时，闭环状态进入与残差上界相关的有界邻域。该定理不要声称全局渐近稳定。

**定理 3.3 慢变优先级下的性能界。** 当 `α_FP(t)` 经过滤波且变化率受限时，利用参数依赖 Lyapunov 函数说明性能损失与 `|dot α_FP|` 有关。该定理为优先级滤波提供理论理由。

**注。** 在定理后说明条件保守性和工程取值。例如：理论条件要求残差界和变化率上界，但实验中通过限幅、滤波和硬安全阈值降低违反条件的风险。

### 5.4 第三章实验定位

第三章实验应验证控制器本身，而不是验证人机仲裁。建议固定参考轨迹和人类输入，先做无人在环的力-位控制对比。若要加入人类输入，只作为附加扰动或参考变化，不应成为本章主线。

对比方法建议包括：

1. 固定笛卡尔阻抗控制；
2. 混合力/位置控制或并联力-位置控制；
3. 固定 `α_FP` 的合作博弈控制；
4. MPC/QP 或 CBF-QP 作为安全强化基线；
5. 本章动态 `α_FP` 合作博弈方法。

指标建议包括：位置 RMS、法向力 RMS、力峰值误差、力越界时间、力抖动、任务空间 jerk、控制输入峰值、平均计算时间。若加入 RCM 工况，再增加 `e_gc` RMS 和峰值。

### 5.5 第三章小结写法

本章小结不要机械复述每节。建议三段：第一段说明本章解决的控制问题；第二段说明主要理论结果；第三段说明实验结论和与第四章的关系。结尾应自然引出：第三章默认期望轨迹已给定或由外部模块生成，实际人机协同任务中人的输入需要被解释和筛选，因此第四章研究动态仲裁。

## 6. 第四章详细修改方案

新的第四章题名为“面向人机协同柔性操作的动态仲裁方法”。本章应说明人在柔性接触任务中为什么需要介入，以及人的介入如何进入参考层而不破坏第三章的力-位控制器。

### 6.1 推荐章节结构

```text
第 4 章 面向人机协同柔性操作的动态仲裁方法
4.1 问题描述与人类输入特征
4.2 人侧监督参考生成与切向/法向分解
4.3 接触安全参考投影
4.4 动态人机仲裁参数设计
4.5 有界性与实时性分析
4.6 仿真与实物实验验证
4.7 本章小结
```

### 6.2 章首两段写法

第一段从第三章控制器的外部参考假设引出：第三章给出了给定参考轨迹下的力-位协同控制器，但在人机协同柔性操作中，参考轨迹并非完全由离线规划器决定。操作者会根据视觉、力反馈或工艺经验给出修正。

第二段说明人类输入的双重性：切向修正可能改善扫描覆盖或避开缺陷，法向输入可能造成过压或接触丢失，短时扰动又不应被解释为真实意图。因此本章的目标是在参考层筛选和仲裁人类输入，使有效修正进入任务参考，使危险输入被削弱。

### 6.3 本章应使用的定义、假设、引理和定理

**定义 4.1 人类监督输入。** 定义主端位移、速度、交互力、输入持续时间、方向一致性和空间风险变量。不要把所有变量都写成模糊控制输入，应先说明物理含义。

**定义 4.2 切向/法向分解。** 由接触法向 `n_c` 构造 `P_N=n_c n_c^T` 和 `P_T=I-P_N`，说明切向输入主要影响轨迹覆盖，法向输入主要影响接触力。

**定义 4.3 安全参考集合。** 利用局部力预测模型构造 `X_s(t)`，包括力边界、工作空间和可选几何约束。该定义是第四章区别于普通共享控制的关键。

**引理 4.1 安全参考投影的有界性。** 如果安全集合非空、闭且局部凸，人侧参考有界，则投影存在且有界。该引理可借鉴童康论文“先给条件，再证明存在性”的方式。

**定义 4.4 人机仲裁参数。** `α_HR` 只作用于参考层，不能出现在第三章的力-位增益表中。若保留 `β`，应明确 `β` 是内部参考融合系数，`α_HR` 是最终人侧安全参考进入期望轨迹的权重。

**引理 4.2 仲裁参数区间不变性。** 若 `α_HR,0∈[α_min,α_max]` 且经一阶滤波生成，则 `α_HR(t)` 保持在区间内，变化率有界。

**定理 4.1 有界参考下的闭环实际有界性。** 固定使用第三章执行层控制器，说明经安全投影和滤波的人侧参考有界，因此进入执行层的期望轨迹及其导数有界，在残差有界条件下闭环保持实际有界。

**注。** 说明该章的安全投影和动态仲裁不等价于严格控制屏障函数。实际实物实验仍需硬安全阈值、速度限幅和力阈值停止策略。

### 6.4 第四章实验定位

第四章实验应固定第三章控制器，只比较不同人机仲裁策略。这样才能回答导师要求的“第 4 章与其他力位协调方法的对比”在新框架中对应到第三章，而第四章则比较仲裁方法本身。

第四章对比方法建议为：

1. 直接接受人类输入；
2. 固定比例共享控制；
3. 单因素 S 型仲裁；
4. 无安全投影的多因素模糊仲裁；
5. 本章含切向/法向分解与安全投影的动态仲裁。

实验工况包括安全切向修正、不安全法向压入、短时扰动、持续目标重定向。指标包括人类修正接受率、危险输入抑制率、法向力峰值、力越界时间、切向轨迹偏移误差、`α_HR` 变化率和操作者输入能量。

### 6.5 第四章贡献表述

第四章贡献不应写成“提出一种全新的模糊逻辑控制方法”。更稳妥的表述是：针对人机协同柔性接触操作中人类输入含义不唯一的问题，构造了包含切向/法向分解、接触力安全投影和多因素动态仲裁的参考层方法，使安全的人类修正能够进入任务参考，同时降低危险输入造成的接触力越界风险。

## 7. 第五章详细修改方案

第五章题名为“人机协同柔性物体操作综合实验验证”。本章应从理论方法章改为实验验证章。其价值在于统一平台、统一工况和统一指标，不在于再提出一个新的双仲裁理论。

### 7.1 推荐章节结构

```text
第 5 章 人机协同柔性物体操作综合实验验证
5.1 综合实验目标与验证逻辑
5.2 仿真与实物实验平台
5.3 实验任务、对比方法与评价指标
5.4 无 RCM 柔性表面操作实验
5.5 RCM 约束下长工具柔性操作实验
5.6 参数敏感性与消融实验
5.7 综合讨论
5.8 本章小结
```

### 7.2 第 5.1 节写法

本节要明确三件事：第一，第三章解决执行层力-位协调；第二，第四章解决参考层人机仲裁；第三，本章验证二者组合后是否仍能在同一闭环中稳定工作。可以写明本章不再提出新的控制律，而是在统一实验任务中检查控制器、仲裁器和安全监督的兼容性。

### 7.3 第 5.2 节写法

实验平台必须具体。应说明机械臂型号、末端工具、柔性材料、力测量方式、主端设备、控制频率、采样频率、重复次数、滤波方式和安全阈值。若使用 Franka、Novint Falcon、6D 力传感器、海绵/硅胶/软泡棉、长工具和简化套管结构，应全部写明。

建议表格如下：

| 类别 | 内容 | 论文中应说明的要点 |
|---|---|---|
| 机器人 | Franka Panda/FR3 或现有七自由度机械臂 | 控制接口、控制频率、力矩/速度限幅 |
| 主端设备 | Novint Falcon 或手柄 | 位移、速度、交互力或按钮输入 |
| 末端工具 | 圆头探针、长工具、腹腔镜抓钳或等效接触杆 | 工具长度、接触点位置、法向定义 |
| 柔性环境 | 海绵、硅胶块、泡棉、橡胶条 | 刚度区间、安装方式、是否可重复 |
| 力测量 | 6D 力传感器或 Franka 外力估计 | 滤波、坐标变换、零偏校准 |
| 安全设置 | 力阈值、速度限幅、急停规则 | 说明保证实验安全，不作为算法性能指标 |

### 7.4 第 5.3 节写法

本节先给对比方法，再给评价指标。不要把指标放到结果后才解释。

对比方法建议分两层：

**控制器层对比**：固定阻抗、混合力/位、MPC/QP 或 CBF-QP、第三章方法。

**系统层消融**：无仲裁、仅第三章控制器、仅第四章仲裁、第三章+第四章完整方法。

评价指标建议包括：

```text
力安全：E_F^RMS、|e_F|max、T_vio、J_F
轨迹质量：E_p^RMS、E_T^RMS、路径覆盖率、jerk
几何约束：E_gc^RMS、E_gc^max
人机协同：R_acc、R_sup、α_HR 平滑性、操作者输入能量
实时性：单周期平均计算时间、最大计算时间、丢帧数
```

每个指标都要给数学定义和物理意义。例如 `T_vio` 比单纯越界次数更适合论文，因为它能与实验时长对应；`R_sup` 应只在有危险法向输入的时间段计算。

### 7.5 第 5.4 节：无 RCM 柔性表面操作实验

无 RCM 实验用于证明方法不是只适用于手术或长工具场景。任务可设置为探针沿柔性表面进行直线或曲线扫描，操作者在中途给出切向修正，柔性材料中包含软区和硬区。该实验不需要额外复杂平台，只需固定海绵/硅胶块和接触探针。

预期结果应是：完整方法能接受切向修正，保持较低力越界时间；固定阻抗在高刚度区力峰值更明显；强力优先或单纯力控会降低切向轨迹覆盖质量；仅力-位控制无法体现人类修正，轨迹仍接近名义路径。

### 7.6 第 5.5 节：RCM 约束下长工具柔性操作实验

有 RCM 实验用于覆盖导师关心的手术训练或固定通道边界。任务可设置为长工具通过套管/固定孔接触柔性材料，沿短路径扫描或完成轻触压入。RCM 不再作为论文标题中的研究对象，而是作为一种几何边界条件。

预期结果应是：完整方法在保持 RCM 误差不明显增大的同时降低力峰值和危险法向输入影响。若某个固定参数方法在力 RMS 上更低，但 RCM 误差或路径误差更大，应如实说明本文追求的是力安全、轨迹覆盖、几何合规和人类修正的综合折中。

### 7.7 第 5.6 节：参数敏感性与消融实验

导师提到参数敏感性，但必须有数据支撑。建议只选少量关键参数，不要做大规模网格：

| 参数 | 范围 | 观察指标 | 预期现象 |
|---|---|---|---|
| `α_FP` 初值/下限 | 低、中、高三档 | 力误差、位置误差、力越界 | 下限过低时轨迹/几何误差增加；过高时力峰值增加 |
| `λ_FP` | 慢、中、快三档 | α 变化率、力抖动、越界时间 | 过快导致抖动，过慢导致响应滞后 |
| `λ_HR` | 慢、中、快三档 | 人类修正接受率、参考平滑性 | 过快跟随抖动，过慢操作者感觉迟滞 |
| 安全余量 `Δ_F` | 小、中、大三档 | 危险输入抑制率、任务误差 | 余量越大越保守，任务覆盖可能下降 |

消融实验建议最少四组：完整方法、去掉安全投影、固定 `α_FP`、固定 `α_HR`。这样能明确说明第三章和第四章模块各自的作用。

## 9. 章节级段落风格规范

每章开头应采用两到三段自然叙述。第一段说明上一章留下的问题，第二段说明本章研究对象和方法，第三段可简述本章结构。不要一开头就列“本文贡献如下”，除非已经进入章节末尾或研究内容小节。

公式出现后，应紧接着解释核心符号和物理含义。例如，写出接触力模型后，应说明 `K_e` 变化为什么会放大压入误差，`B_e` 为什么影响接触瞬态，残差项包含哪些实际来源。解释应围绕变量本身，不要使用“换句话说”“需要强调的是”等重复提示语。

理论分析部分应遵循“假设—定义—引理—定理—证明—注”的顺序。假设只限定系统、输入、扰动和参数范围；定义固定概念；引理解决中间步骤；定理给出主要性质；证明围绕已有公式逐步展开；注说明保守性和工程取值。不要把“实物实验平台采用 Franka”写成假设，也不要把“本文方法有效”写成定理。

实验分析部分应遵循“设置—指标—结果—原因—边界”的顺序。先说明实验平台和参数，再给指标定义，然后看图表结果，最后解释结果为什么支撑方法设计。若某一基线在单项指标上优于本文方法，应如实说明，并解释本文方法的综合目标。
